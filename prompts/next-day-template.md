# Prompt template для следующего дня

```text
Аналогично для следующего дня.

Проверь приложенную работу Настюшика. Сформируй:
1. PDF с обратной связью для ребёнка по результатам дня.
2. PDF с обратной связью для родителя.
3. PDF с конкретными заданиями на следующий день, чтобы можно было сразу выдать ребёнку.
4. PDF с ответами и акцентами для проверки.

Учитывай текущую capability matrix:
- основной curriculum target — углублённая федеральная программа из asserts/FRP_matematika_7-9_uglublennyi_uroven_2025.pdf;
- порядок разделов и рекомендованные часы бери из data/curriculum/advanced_grade7.csv;
- контрольные asserts/*7_klass.pdf трактуй как обязательный нижний порог, но не как верхнюю границу сложности;
- используй отдельные матрицы алгебры, геометрии и вероятности со статистикой из data/capability_matrices;
- evidence из одного направления не повышает статус другого без отдельного задания;
- статус NEW/0 означает «ещё не диагностировано», а не «ребёнок не умеет»;
- не включай все направления в один день формально: выбери один основной gate и не более одного короткого поддерживающего переноса;
- основную дисциплину выбери автоматически: сначала незавершённая мысль или ответ «не знаю» из последней работы, иначе выравнивай последние восемь основных дней к пропорции алгебра : геометрия : вероятность и статистика = \(4:3:1\);
- внутри выбранной дисциплины бери первый незакрытый раздел по полю sequence, если latest evidence не показывает более раннюю блокирующую предпосылку;
- для ответа «не знаю» не требуй угадывания: укажи конкретный источник и фрагмент для изучения, затем дай близкую задачу и задачу на перенос;
- в front matter задания укажи primary_domain и curriculum_unit, чтобы следующий запуск мог восстановить историю автоматического выбора;
- сильные стороны: скобки, уравнения, особые случаи, текстовые задачи через таблицу;
- текущие акценты: последний шаг в уравнении, десятичные коэффициенты со знаками, неравенства с отрицательным множителем, смешанные задания без подсказки типа;
- формат формул: все математические выражения писать в LaTeX-нотации через \( ... \) или \[ ... \];
- примеры формата: \(-3x \le 12 \Rightarrow x \ge -4\), \(0{,}5x \cdot 8x^2 = 4x^3\), \(50^\circ\);
- не использовать plain-text варианты x^2, <=, >=, ->, * в материалах для ребёнка и родителя;
- в итоговых PDF формулы должны быть отрендерены, а не показаны буквальным текстом \(...\);
- preferred workflow: создать Markdown-исходники в artifacts/generated/source/dayNN/ и собрать их через python3 scripts/build_day_pdfs.py --day NN --update-manifest --render-preview;
- стиль: поддерживающий, обращаться к ребёнку как “Настюшик”.
- не давать изолированные задания уровня «назови действие», «подпиши сложение или умножение» и другие классификации очевидного;
- если нужно закрепить локальный навык, встраивать его в содержательную задачу: сравнение гипотез, поиск контрпримера, восстановление условия, доказательство невозможности или обратную задачу;
- каждый день включать хотя бы одну цепочку «наблюдение - гипотеза - обоснование - применение»;
- движение к олимпиадному уровню строить через выбор идеи, доказательство, обобщение и перенос, а не через увеличение чисел или объёма однотипных упражнений;
- углублённый curriculum gate обязателен, олимпиадный элемент является отдельным слоем: примерно \(50\text{--}60\%\) времени на текущую основу, \(30\text{--}40\%\) на углублённую содержательную задачу и до \(10\%\) на необязательный исследовательский перенос;
- технических однотипных пунктов давать не более двух подряд; проверять навык преимущественно в новом контексте;
- уважать субъективное ощущение уровня сложности: не маскировать примитивное упражнение игровым названием, а повышать реальную когнитивную сложность.
```
