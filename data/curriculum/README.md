# Curriculum map

Файл [advanced_grade7.csv](advanced_grade7.csv) фиксирует порядок разделов федеральной рабочей программы по математике углублённого уровня для \(7\)-го класса.

Источник: [локальная копия программы](../../asserts/FRP_matematika_7-9_uglublennyi_uroven_2025.pdf), Москва, 2025 год. [Официальная публикация](https://edsoo.ru/wp-content/uploads/2025/06/06_frp_matematika-5-9-klassy_ugl_17062025_itog-na-sajt.pdf).

| Направление | Часы | Доля основных дней |
|---|---:|---:|
| Алгебра | \(136\) | \(4/8\) |
| Геометрия | \(102\) | \(3/8\) |
| Вероятность и статистика | \(34\) | \(1/8\) |
| Всего | \(272\) | \(8/8\) |

## Поля

| Поле | Значение |
|---|---|
| domain | предметная матрица |
| sequence | порядок раздела внутри направления |
| unit | название раздела |
| hours | рекомендованная программой нагрузка |
| capabilities | связанные capability через точку с запятой |

Curriculum map не хранит оценку ребёнка. Статусы и evidence находятся в **data/capability_matrices/**.

## Правило выбора

Если последняя работа не требует коррекционного продолжения, генератор выбирает недопредставленное направление относительно пропорции \(4:3:1\), затем первый незакрытый раздел по полю **sequence**. Ответ «не знаю» получает приоритет на один день и должен сопровождаться конкретным источником.
