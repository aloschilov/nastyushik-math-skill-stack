# Предметные capability matrix

В репозитории используется единый математический контур с тремя независимыми матрицами:

- **algebra.csv** — алгебра и алгебраическое рассуждение;
- **geometry.csv** — геометрические объекты, измерения и доказательные связи;
- **probability_statistics.csv** — данные, статистика и вероятность.

Основной ориентир — федеральная программа углублённого уровня для (7\text{--}9)-х классов. Порядок разделов (7)-го класса и нагрузка (136+102+34=272) часа зафиксированы в [advanced_grade7.csv](../curriculum/advanced_grade7.csv). Матрицы ниже хранят состояние ребёнка; curriculum-файл хранит порядок обучения. Это разные сущности.

Схема всех файлов одинакова:

| Поле | Значение |
|---|---|
| capability | стабильный машинный идентификатор навыка |
| status | PASS, WATCH, TRAIN или NEW |
| level | уровень от \(0\) до \(4\) |
| evidence | последнее наблюдаемое свидетельство |
| next_gate | ближайшая проверяемая граница перехода |

Результат в одном направлении не меняет автоматически статус в другом. Общий дневной комплект может включать несколько предметов, но каждое наблюдение записывается в соответствующий CSV.

Не каждый capability обязан входить в curriculum-карту: уже закреплённые опорные навыки могут оставаться в матрице как поддерживающие. Но каждый capability, указанный в curriculum-карте, обязан существовать ровно в одной предметной матрице.
