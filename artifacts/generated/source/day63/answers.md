> Главный акцент: при сложении одинаковых одночленов удваивается коэффициент, но степень буквы не меняется. При умножении перемножаются коэффициенты и складываются степени.

# Блок 1. Разные действия

1. \(4x+4x=8x\) - сложение.
2. \(4x\cdot4x=16x^2\) - умножение.
3. \(6p+6p=12p\) - сложение.
4. \((2p)\cdot(2p)=4p^2\) - умножение.

Исправленные примеры:

\[
(m+5)^2=m^2+(5m+5m)+25=m^2+10m+25,
\]

\[
(2p+3)^2=(2p)^2+(6p+6p)+9=4p^2+12p+9.
\]

# Блок 2. Квадраты суммы

1.
\[
A=x^2,\qquad B=2\cdot x\cdot3=6x,\qquad C=3^2=9,
\]
\[
(x+3)^2=x^2+6x+9.
\]

2.
\[
A=(2a)^2=4a^2,\qquad B=2\cdot2a\cdot1=4a,\qquad C=1,
\]
\[
(2a+1)^2=4a^2+4a+1.
\]

3.
\[
A=(3m)^2=9m^2,\qquad B=2\cdot3m\cdot4=24m,\qquad C=16,
\]
\[
(3m+4)^2=9m^2+24m+16.
\]

# Блок 3. Исправление ошибок

1. Ошибочен средний член \(4y^2\). Верно:

\[
(y+4)^2=y^2+8y+16.
\]

2. Ошибочен первый член \(2n^2\), потому что \((2n)^2=4n^2\). Верно:

\[
(2n+5)^2=4n^2+20n+25.
\]

# Блок 4. Проверка

При \(n=1\):

\[
(2\cdot1+5)^2=7^2=49,
\]

\[
4\cdot1^2+20\cdot1+25=4+20+25=49.
\]

Значения совпали.

# Блок 5. Поддержание

1.
\[
(k+1)(k-4)=k^2-4k+k-4=k^2-3k-4.
\]

2.
\[
7-3x\ge16\Rightarrow-3x\ge9\Rightarrow x\le-3.
\]

3. Вертикальный угол равен \(112^\circ\). Два смежных угла равны \(180^\circ-112^\circ=68^\circ\). Ответ: \(112^\circ\), \(68^\circ\), \(68^\circ\).

# Что считать успехом

- Ребёнок проговаривает разницу между сложением и умножением одинаковых одночленов.
- Во всех трёх квадратах суммы отдельно получены \(u^2\), \(2uv\) и \(v^2\).
- В примерах с (2a) и (3m) коэффициент тоже возведён в квадрат.
- Независимая подстановка даёт одинаковые значения без подгонки вычисления.
- Квадрат разности пока не используется.
