> Пересмотри только первый разобранный пример на квадрат суммы. На каждой строке называй действие: «складываю» или «умножаю». Остановись до квадрата разности. Не более 6 минут.

> Два разных действия:
\[
T+T=2T,\qquad T\cdot T=T^2.
\]

# Блок 1. Разведи действия

Вычисли и рядом подпиши: «сложение» или «умножение».

1. \(4x+4x\)
2. \(4x\cdot4x\)
3. \(6p+6p\)
4. \((2p)\cdot(2p)\)

Затем восстанови вчерашние примеры:

1. \((m+5)^2=m^2+(5m+5m)+25\)
2. \((2p+3)^2=(2p)^2+(6p+6p)+9\)

# Блок 2. Три отдельные части

Для каждого примера сначала вычисли отдельно:

\[
A=u^2,\qquad B=2uv,\qquad C=v^2,
\]

и только потом запиши \(A+B+C\).

1. \((x+3)^2\)
2. \((2a+1)^2\)
3. \((3m+4)^2\)

# Блок 3. Найди и исправь ошибку

1. \((y+4)^2=y^2+4y^2+16\)
2. \((2n+5)^2=2n^2+20n+25\)

В каждом примере подчеркни только ошибочный член и запиши правильный результат.

# Блок 4. Независимая проверка

Проверь исправленное равенство для \((2n+5)^2\) при \(n=1\).

1. Сначала отдельно вычисли выражение со скобками.
2. Закрой эту строку листком.
3. Отдельно вычисли значение многочлена.
4. Сравни два числа.

# Блок 5. Старые навыки на поддержание

1. Раскрой скобки и запиши итог: \((k+1)(k-4)\).
2. Реши неравенство: \(7-3x\ge16\).
3. При пересечении двух прямых \(\angle 1=112^\circ\). Найди три оставшихся угла.
