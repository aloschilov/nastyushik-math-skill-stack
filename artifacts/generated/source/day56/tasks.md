> Видео дня: [«Решение линейных неравенств»](https://interneturok.ru/h/biblioteka/algebra/8-klass/reshenie-lineynih-neravenstv/1).
>
> Посмотри только объяснение правила и первый полностью разобранный пример с делением на отрицательное число. На сегодня достаточно 7-10 минут.

> Команда дня: у знака есть два независимых свойства. Строгость сохраняем: \(<\) остаётся строгим. Направление меняем только при умножении или делении на отрицательное число.

# Блок 1. Поставь знак в ответе

Не решай заново. Впиши только один подходящий знак.

1. \(-3x < 12 \Rightarrow x\;?\;-4\)
2. \(-3x \le 12 \Rightarrow x\;?\;-4\)
3. \(5x > -10 \Rightarrow x\;?\;-2\)
4. \(-0{,}5x \ge 2 \Rightarrow x\;?\;-4\)

# Блок 2. Реши неравенства

Перед ответом подпиши две вещи: «строгий / нестрогий» и «развернуть / оставить».

1. \(-4x < 20\)
2. \(-2x \ge -14\)
3. \(0{,}5x \le 3\)
4. \(-0{,}25x > 1\)
5. \(3 - 2x < 11\)

# Блок 3. Проверь границу

1. Подходит ли \(x=-5\) для ответа \(x>-5\)?
2. Подходит ли \(x=7\) для ответа \(x\le7\)?

# Блок 4. Старый навык: общий множитель

Вынеси общий множитель, затем один пример на выбор проверь раскрытием скобок.

1. \(12x^2 + 18x + 6\)
2. \(-8a^2 + 12a\)
3. \(0{,}6p^2 + 1{,}2p\)

# Блок 5. Геометрия на поддержание

Запиши не только ответ, но и вычисление.

1. Один из смежных углов равен \(47^\circ\). Найди второй.
2. При пересечении двух прямых один угол равен \(128^\circ\). Найди остальные три угла.

Вопрос в конце: что может измениться при делении неравенства на отрицательное число, а что измениться не может?
