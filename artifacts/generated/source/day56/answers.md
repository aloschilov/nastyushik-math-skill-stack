> Главный акцент: направление и строгость знака проверяются отдельно. Деление на отрицательное число разворачивает знак, но не добавляет и не убирает равенство.

# Блок 1. Поставить знак

1. \(-3x < 12 \Rightarrow x > -4\).
2. \(-3x \le 12 \Rightarrow x \ge -4\).
3. \(5x > -10 \Rightarrow x > -2\).
4. \(-0{,}5x \ge 2 \Rightarrow x \le -4\).

# Блок 2. Решить неравенства

1. Строгий, развернуть: \(-4x < 20 \Rightarrow x > -5\).
2. Нестрогий, развернуть: \(-2x \ge -14 \Rightarrow x \le 7\).
3. Нестрогий, оставить: \(0{,}5x \le 3 \Rightarrow x \le 6\).
4. Строгий, развернуть: \(-0{,}25x > 1 \Rightarrow x < -4\).
5. Строгий, развернуть: \(3-2x<11 \Rightarrow -2x<8 \Rightarrow x>-4\).

# Блок 3. Проверить границу

1. Нет: \(-5\) не больше \(-5\).
2. Да: знак \(\le\) разрешает равенство.

# Блок 4. Общий множитель

1. \(12x^2 + 18x + 6 = 6(2x^2 + 3x + 1)\).
2. \(-8a^2 + 12a = -4a(2a - 3)\).
3. \(0{,}6p^2 + 1{,}2p = 0{,}6p(p + 2)\).

Пример проверки: \(-4a(2a-3)=-8a^2+12a\).

# Блок 5. Геометрия

1. \(180^\circ-47^\circ=133^\circ\).
2. Вертикальный угол равен \(128^\circ\). Два смежных угла равны \(180^\circ-128^\circ=52^\circ\). Ответ: \(128^\circ\), \(52^\circ\), \(52^\circ\).

# Что считать успехом

- Во всех строгих неравенствах ответ остаётся строгим.
- Направление знака меняется только при делении на отрицательное число.
- В блоке 4 общий множитель вынесен без потери знаков.
