> Главный акцент: формула не является новым действием. Это уже освоенное умножение одинаковых двучленов с двумя равными средними произведениями.

# Блок 1. Вывод формулы

\[
(a+b)^2=(a+b)(a+b)=a^2+ab+ab+b^2=a^2+2ab+b^2.
\]

Средний член \(2ab\) появился из суммы двух одинаковых произведений: \(ab+ab=2ab\).

# Блок 2. Квадраты суммы

1.
\[
(x+2)^2=x^2+2\cdot x\cdot2+2^2=x^2+4x+4.
\]

2.
\[
(m+5)^2=m^2+2\cdot m\cdot5+5^2=m^2+10m+25.
\]

3.
\[
(2p+3)^2=(2p)^2+2\cdot2p\cdot3+3^2=4p^2+12p+9.
\]

# Блок 3. Пропущенный член

Пропущен средний член \(2\cdot y\cdot4=8y\). Верно:

\[
(y+4)^2=y^2+8y+16.
\]

# Блок 4. Проверка

При \(y=1\):

\[
(1+4)^2=25,\qquad 1^2+8\cdot1+16=25.
\]

# Блок 5. Поддержание

1.
\[
(n+2)(n-3)=n^2-3n+2n-6=n^2-n-6.
\]

2.
\[
6-4x\ge14\Rightarrow-4x\ge8\Rightarrow x\le-2.
\]

3. Вертикальный угол равен \(104^\circ\). Два смежных угла равны \(180^\circ-104^\circ=76^\circ\). Ответ: \(104^\circ\), \(76^\circ\), \(76^\circ\).

# Что считать успехом

- Во всех трёх примерах записан средний член.
- Ребёнок объясняет \(2ab\) как сумму \(ab+ab\).
- Квадрат разности и другие формулы пока не используются.
