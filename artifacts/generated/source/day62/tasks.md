> Формула дня:
\[
(a+b)^2=a^2+2ab+b^2.

# Блок 1. Откуда взялась формула

Начни с

\[
(a+b)^2=(a+b)(a+b).
\]

1. Запиши четыре произведения.
2. Собери два одинаковых средних слагаемых.
3. Получи формулу \(a^2+2ab+b^2\).

# Блок 2. Примени квадрат суммы

В каждом примере отдельно подпиши первый квадрат, средний член \(2ab\) и второй квадрат.

1. \((x+2)^2\)
2. \((m+5)^2\)
3. \((2p+3)^2\)

# Блок 3. Найди пропущенный член

Ученик написал:

\[
(y+4)^2=y^2+16.
\]

Какой член пропущен? Запиши правильный результат.

# Блок 4. Проверка

Подставь \(y=1\) в \((y+4)^2\) и в правильный многочлен из Блока 3. Сравни значения.
