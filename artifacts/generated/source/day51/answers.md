> Главный акцент: сначала определяем знак результата, потом считаем числа и буквы. В неравенствах сначала определяем знак делителя.

# Блок 1. Сначала знак

1. \((-3) \cdot (-5) = 15\).
2. \((-0{,}5x) \cdot (-2) = x\).
3. \((-3a) \cdot (-5) = 15a\).
4. \((-2x) \cdot (-3) = 6x\).
5. \((-0{,}25p) \cdot (-4) = p\).
6. \((-4m) \cdot (-0{,}5m) = 2m^2\).

# Блок 2. Раскрыть скобки

1. \(-0{,}5x(6x - 2) = -0{,}5x \cdot 6x + (-0{,}5x) \cdot (-2) = -3x^2 + x\).
2. \(-3a(2a - 5) = -3a \cdot 2a + (-3a) \cdot (-5) = -6a^2 + 15a\).
3. \(-2m(4m - 3) = -8m^2 + 6m\).
4. \(-0{,}25p(8p - 4) = -2p^2 + p\).

# Блок 3. Раскрыть и собрать подобные

1. \(-0{,}5x(6x - 2) + 2x = -3x^2 + x + 2x = -3x^2 + 3x\).
2. \(-3a(2a - 5) - a = -6a^2 + 15a - a = -6a^2 + 14a\).
3. \(-2m(4m - 3) + m = -8m^2 + 6m + m = -8m^2 + 7m\).
4. \(-0{,}25p(8p - 4) + 3p = -2p^2 + p + 3p = -2p^2 + 4p\).

# Блок 4. Неравенства

1. \(-0{,}25x > 1 \Rightarrow x < -4\).
2. \(0{,}2x < -1 \Rightarrow x < -5\).
3. \(-4x \ge 12 \Rightarrow x \le -3\).
4. \(-0{,}5x \le -5 \Rightarrow x \ge 10\).
5. \(0{,}5x \ge -3 \Rightarrow x \ge -6\).

# Блок 5. Геометрия

1. \(180^\circ - 75^\circ = 105^\circ\).
2. \(4x + 10^\circ = 90^\circ \Rightarrow 4x = 80^\circ \Rightarrow x = 20^\circ\).

# Что считать успехом

- В примерах с двумя минусами второе слагаемое стало положительным.
- В неравенствах 1, 3, 4 знак перевёрнут, потому что делим на отрицательное число.
- В неравенствах 2 и 5 знак не перевёрнут, потому что делим на положительное число.
- В геометрии правила смежных и вертикальных углов применены без новой подсказки.
