> Главный критерий: ребёнок выбирает направление формулы по цели задачи. Для доказательства общего утверждения должен появиться общий знак \(2ab>0\), а для делимости - явный множитель \(8\).

# Блок 1. От примера к утверждению для всех

1. Так как \(a>0\) и \(b>0\), произведение \(ab>0\). Следовательно,

\[
2ab>0.
\]

2.

\[
(a+b)^2-(a^2+b^2)=2ab>0,
\]

поэтому

\[
(a+b)^2>a^2+b^2.
\]

3. Для любых положительных \(a\) и \(b\) квадрат их суммы строго больше суммы их квадратов.

4. Один контрпример достаточен, чтобы опровергнуть утверждение «для всех». Но один удачный пример подтверждает только этот пример. Новый вывод доказан знаком \(2ab>0\) для произвольных положительных \(a\) и \(b\).

# Блок 2. Два направления и два корня

1.

\[
81y^2-25=(9y)^2-5^2=(9y-5)(9y+5).
\]

2.

\[
\begin{aligned}
(4x-1)(4x+1)&=63,\\
16x^2-1&=63,\\
16x^2&=64,\\
x^2&=4.
\end{aligned}
\]

Поэтому

\[
x=2\quad\text{или}\quad x=-2.
\]

3.

\[
(8-1)(8+1)=7\cdot9=63,
\]

\[
(-8-1)(-8+1)=(-9)\cdot(-7)=63.
\]

4. Пропущено \(x=-2\), поскольку

\[
(-2)^2=4.
\]

# Блок 3. Нижняя граница не равна числу шагов

1. Ошибочно взят множитель \(8\). По формуле разности квадратов:

\[
\begin{aligned}
15^2-8^2
&=(15-8)(15+8)\\
&=7\cdot23\\
&=161.
\end{aligned}
\]

Значит,

\[
17+19+\ldots+29=161.
\]

2.

\[
\begin{aligned}
2m+1&=(m+1)^2-m^2,\\
2m+3&=(m+2)^2-(m+1)^2,\\
&\ \vdots\\
2n-1&=n^2-(n-1)^2.
\end{aligned}
\]

После сложения промежуточные квадраты сокращаются:

\[
(2m+1)+(2m+3)+\ldots+(2n-1)=n^2-m^2.
\]

3. Для первого члена \(31=2\cdot15+1\), поэтому \(m=15\). Для последнего \(59=2\cdot30-1\), поэтому \(n=30\):

\[
31+33+\ldots+59=30^2-15^2=900-225=675.
\]

Членов \(30-15=15\), среднее равно

\[
\frac{31+59}{2}=45.
\]

Проверка:

\[
15\cdot45=675.
\]

# Блок 4. Довести делимость до множителя восьми

1. Если \(N\) нечётно, то соседние с ним числа \(N-1\) и \(N+1\) чётны и отличаются на \(2\). Поэтому это соседние чётные числа.

2. Среди двух соседних чётных чисел одно имеет вид \(4q\), а другое содержит ещё один множитель \(2\).

3.

\[
N^2-1=(N-1)(N+1).
\]

Один множитель делится на \(4\), другой на \(2\), поэтому произведение делится на

\[
4\cdot2=8.
\]

4.

\[
\begin{aligned}
\frac{51^2-1}{8}
&=\frac{(51-1)(51+1)}{8}\\
&=\frac{50\cdot52}{8}\\
&=325.
\end{aligned}
\]

5. Последовательные чётные числа имеют вид \(2k\) и \(2k+2\):

\[
2k(2k+2)=4k(k+1).
\]

Произведение \(k(k+1)\) чётно, поэтому для некоторого целого \(q\)

\[
k(k+1)=2q.
\]

Следовательно,

\[
4k(k+1)=8q.
\]

# Необязательный олимпиадный перенос

Если число чётно и равно \(2k\), то

\[
(2k)^2=4k^2,
\]

поэтому остаток при делении на \(4\) равен \(0\).

Если число нечётно и равно \(2k+1\), то

\[
(2k+1)^2=4k^2+4k+1=4k(k+1)+1,
\]

поэтому остаток равен \(1\). Других случаев нет.

# Ответ на вопрос о методе

Разность превращалась в произведение при разложении \(81y^2-25\), исправлении \(15^2-8^2\) и доказательстве делимости \(N^2-1\). Произведение превращалось в разность при решении \((4x-1)(4x+1)=63\).

# Что считать успехом

- Общий вывод записан через \(2ab>0\).
- \(81y^2-25\) разложено в два множителя.
- Для \(x^2=4\) найдены и проверены оба значения.
- Ошибка \(23\cdot8\) исправлена на \(23\cdot7\).
- Общая телескопическая формула получена по трём строкам.
- Делимость завершена явным множителем \(8\) или записью \(8q\).
