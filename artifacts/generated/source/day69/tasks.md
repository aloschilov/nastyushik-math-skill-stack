# Блок 1. От примера к утверждению для всех

Известно:

\[
(a+b)^2-(a^2+b^2)=2ab.
\]

Пусть \(a\) и \(b\) - произвольные положительные числа.

1. Какой знак имеет \(2ab\)? Объясни через свойства положительных чисел.
2. Сравни \((a+b)^2\) и \(a^2+b^2\). Запиши строгий знак.
3. Сформулируй одним предложением вывод сразу для всех положительных \(a\) и \(b\).
4. Объясни, почему проверка только пары \((1,1)\) могла опровергнуть исходное равенство, но не могла доказать твой новый вывод для всех пар.

# Блок 2. Два направления и два корня

1. Разложи на множители:

\[
81y^2-25.
\]

2. Реши, не раскрывая произведение обычным умножением:

\[
(4x-1)(4x+1)=63.
\]

3. Проверь подстановкой каждое найденное значение.
4. В чужом решении после строки \(x^2=4\) записано только \(x=2\). Назови пропущенное решение и объясни, почему оно подходит.

# Блок 3. Нижняя граница не равна числу шагов

1. Исправь цепочку:

\[
15^2-8^2=(15+8)\cdot8=184.
\]

Назови ошибочный множитель и получи правильную сумму

\[
17+19+\ldots+29.
\]

2. Восстанови общий телескоп. Запиши первую, вторую и последнюю строки для

\[
2k+1=(k+1)^2-k^2,
\]

когда \(k=m,m+1,\ldots,n-1\). Затем сложи их и получи общую формулу.

3. Примени формулу:

\[
31+33+\ldots+59.
\]

Проверь ответ через число членов и среднее первого и последнего.

# Блок 4. Довести делимость до множителя восьми

Пусть \(N\) - нечётное целое число.

1. Объясни, почему \(N-1\) и \(N+1\) являются соседними чётными числами.
2. Объясни, почему одно из них делится на \(4\), а второе делится на \(2\).
3. Используй

\[
N^2-1=(N-1)(N+1)
\]

и закончи доказательство делимости \(N^2-1\) на \(8\).

\medskip

4. Не вычисляя \(51^2\), найди

\[
\frac{51^2-1}{8}.
\]

5. Перенеси идею: докажи, что произведение любых двух последовательных чётных чисел делится на \(8\).

# Необязательный олимпиадный перенос

Докажи, что квадрат целого числа при делении на \(4\) может давать остаток только \(0\) или \(1\). Разбери отдельно чётное число \(2k\) и нечётное число \(2k+1\).
