# Где оборвался перенос

## 1. Один пример не заменяет доказательство для всех

В пункте про положительные \(a\) и \(b\) ты ещё раз проверила пару \((1,1)\). Это доказывает только факт для этой пары. Общий переход должен использовать положительность произведения:

\[
a>0,\quad b>0
\quad\Rightarrow\quad
2ab>0.
\]

Поэтому

\[
(a+b)^2-(a^2+b^2)=2ab>0
\]

сразу для всех положительных \(a\) и \(b\).

## 2. Разность квадратов нужно увидеть целиком

Запись

\[
49x^2-16
\]

содержит два квадрата:

\[
49x^2=(7x)^2,\qquad16=4^2.
\]

Значит,

\[
49x^2-16=(7x-4)(7x+4).
\]

Отдельные записи \(7\cdot7\cdot x\cdot x\) и \(4\cdot4\) верны, но разложение на два множителя ещё не завершено.

## 3. Квадрат не помнит знак

Ты дошла до

\[
x^2=9
\]

и записала \(x=3\). Но

\[
(-3)^2=9
\]

тоже верно. Поэтому решений два:

\[
x=3\quad\text{или}\quad x=-3.
\]

## 4. В границах участвует разность индексов

Для цепочки от \(17\) до \(29\) после сокращения осталось

\[
15^2-8^2.
\]

По разности квадратов:

\[
15^2-8^2=(15-8)(15+8)=7\cdot23=161.
\]

В работе получилось \(23\cdot8\). Число \(8\) является нижней границей, но число шагов равно \(15-8=7\).
