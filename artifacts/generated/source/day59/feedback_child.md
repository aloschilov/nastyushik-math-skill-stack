# Главная точка роста

Складывать можно только подобные слагаемые. У \(3x\) и \(2x\) одинаковая буквенная часть, поэтому

\[
3x+2x=5x.
\]

Число \(6\) не содержит \(x\), поэтому оно остаётся отдельно:

\[
x^2+3x+2x+6=x^2+5x+6.
\]

Нельзя превращать \(3x+2x+6\) в \(11x\): свободное число \(6\) не стало слагаемым с \(x\).

# Почему проверка не заметила ошибку

При \(x=1\) свободное число \(6\) и ошибочно созданное слагаемое \(6x\) дают одно и то же число \(6\). Поэтому неверная запись случайно прошла одну проверку. Ты выполнила данную команду правильно; просто сама точка \(x=1\) оказалась неудачной для поиска именно этой ошибки.
