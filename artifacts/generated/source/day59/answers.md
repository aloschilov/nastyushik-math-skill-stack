> Главный акцент: свободный член не складывается с коэффициентами при переменной. Сначала ребёнок должен увидеть тип каждого слагаемого, затем выполнять арифметику.

# Блок 1. Три группы

1. \(x^2+3x+2x+6=x^2+5x+6\).
2. \(a^2+4a+a+4=a^2+5a+4\).
3. \(m^2+5m+2m+10=m^2+7m+10\).
4. \(p^2-2p+3p-6=p^2+p-6\).

# Блок 2. Два произведения

Первый пример:

\[
(y+2)(y+4)=y^2+4y+2y+8=y^2+6y+8.
\]

Второй пример:

\[
(t+3)(t-1)=t^2-t+3t-3=t^2+2t-3.
\]

# Блок 3. Исправление ошибки

Число \(2\) ошибочно сложили с коэффициентами при \(z\). Верно:

\[
z^2+2z+z+2=z^2+3z+2.
\]

# Блок 4. Проверка

При \(x=0\):

\[
(0+2)(0+3)=6, \qquad 0^2+11\cdot0=0.
\]

При \(x=2\):

\[
(2+2)(2+3)=20, \qquad 2^2+11\cdot2=26.
\]

Записи дают разные значения, поэтому равенство неверно. Совпадение в одной точке не доказывает, что выражения равны при всех значениях переменной.

# Блок 5. Поддержание

1. Неравенство:

\[
3-5x\ge13\Rightarrow-5x\ge10\Rightarrow x\le-2.
\]

2. Вертикальный угол равен \(74^\circ\). Каждый смежный с ним угол равен \(180^\circ-74^\circ=106^\circ\). Ответ: \(74^\circ\), \(106^\circ\), \(106^\circ\).

# Что считать успехом

- Во всех четырёх исправлениях число без буквы осталось отдельным.
- В двух новых произведениях записаны все четыре произведения.
- Ребёнок словами указывает: складывать можно слагаемые с одинаковой буквенной частью и одинаковой степенью.
