# Мини-памятка

Угол состоит из двух лучей, выходящих из одной точки. Эта точка называется вершиной.

\[
\angle AOB
\]

Вершина \(O\) стоит посередине названия.

# Блок 1. Неравенства: короткая разминка

> Если делишь на отрицательное число, знак переворачивается. Проверь это в каждом номере.

1. \(-6x \le -18\)
2. \(-3x > -6\)
3. \(-4x \ge 20\)
4. \(-0{,}5x < 2\)
5. \(-2(x - 3) \le 10\)
6. \(-5(x + 1) > 15\)

# Блок 2. Назови и нарисуй углы

1. Нарисуй угол \(AOB\). Отметь вершину.
2. Нарисуй острый угол \(KLM\).
3. Нарисуй прямой угол \(ABC\).
4. Нарисуй тупой угол \(MON\).
5. Нарисуй развёрнутый угол \(PQR\).

# Блок 3. Сложение и вычитание углов

1. Луч \(OB\) внутри угла \(AOC\). \(\angle AOB = 35^\circ\), \(\angle BOC = 25^\circ\). Найди \(\angle AOC\).
2. \(\angle AOC = 90^\circ\), \(\angle AOB = 38^\circ\). Найди \(\angle BOC\).
3. \(\angle MON = 120^\circ\), луч \(OK\) делит его пополам. Найди каждый угол.
4. \(\angle DEF = 75^\circ\), луч \(EG\) внутри него, \(\angle DEG = 20^\circ\). Найди \(\angle GEF\).

# Блок 4. Алгебра на поддержание

1. \((7a - 3b) - (2a - 5b) =\)
2. \(6x^2 - 4x + 3x^2 + x =\)
3. \(4(x - 3) = 20\)
4. Проверь при \(x = 2\): \(3(x + 1)\) и \(3x + 1\). Равны или не равны?

# Блок 5. Геометрия на поддержание

1. Один из смежных углов равен \(73^\circ\). Найди второй.
2. При пересечении двух прямых один угол равен \(55^\circ\). Найди остальные три угла.
