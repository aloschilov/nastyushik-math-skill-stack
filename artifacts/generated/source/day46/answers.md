> Главный акцент: новая геометрия должна быть спокойной, а в неравенствах проверяем один рефлекс - знак переворачивается при делении на отрицательное число.

# Блок 1. Неравенства

1. \(-6x \le -18 \Rightarrow x \ge 3\).
2. \(-3x > -6 \Rightarrow x < 2\).
3. \(-4x \ge 20 \Rightarrow x \le -5\).
4. \(-0{,}5x < 2 \Rightarrow x > -4\).
5. \(-2x + 6 \le 10 \Rightarrow -2x \le 4 \Rightarrow x \ge -2\).
6. \(-5x - 5 > 15 \Rightarrow -5x > 20 \Rightarrow x < -4\).

# Блок 2. Назови и нарисуй углы

Рисунки проверяются по трём условиям:

- вершина подписана средней буквой;
- у угла две стороны-луча;
- тип угла соответствует заданию: острый меньше \(90^\circ\), прямой \(90^\circ\), тупой между \(90^\circ\) и \(180^\circ\), развёрнутый \(180^\circ\).

# Блок 3. Сложение и вычитание углов

1. \(\angle AOC = 35^\circ + 25^\circ = 60^\circ\).
2. \(\angle BOC = 90^\circ - 38^\circ = 52^\circ\).
3. Каждый угол равен \(120^\circ : 2 = 60^\circ\).
4. \(\angle GEF = 75^\circ - 20^\circ = 55^\circ\).

# Блок 4. Алгебра

1. \((7a - 3b) - (2a - 5b) = 7a - 3b - 2a + 5b = 5a + 2b\).
2. \(6x^2 - 4x + 3x^2 + x = 9x^2 - 3x\).
3. \(4(x - 3) = 20 \Rightarrow x - 3 = 5 \Rightarrow x = 8\).
4. При \(x = 2\): \(3(x + 1) = 9\), \(3x + 1 = 7\). Не равны.

# Блок 5. Геометрия

1. \(180^\circ - 73^\circ = 107^\circ\).
2. Остальные углы: \(125^\circ\), \(55^\circ\), \(125^\circ\).

# Что считать успехом

- В неравенствах 1-6 знак перевёрнут во всех номерах.
- В названиях углов вершина стоит посередине.
- В задачах на сумму углов ребёнок понимает, когда складывать, а когда вычитать.
- В алгебре не вернулась ошибка с минусом перед скобкой.
