# Блок 2. Правило смежных углов

1. Один из смежных углов равен \(40^\circ\). Найди второй.
2. Один из смежных углов равен \(128^\circ\). Найди второй.
3. Смежные углы равны \(x\) и \(2x\). Найди оба угла.
4. Смежные углы равны \(x + 10^\circ\) и \(2x - 10^\circ\). Найди \(x\) и оба угла.

# Блок 3. Правило вертикальных углов

1. Один из вертикальных углов равен \(68^\circ\). Найди второй вертикальный.
2. При пересечении двух прямых один угол равен \(115^\circ\). Найди остальные три угла.
3. Вертикальные углы равны \(3x + 15^\circ\) и \(90^\circ\). Найди \(x\).
4. На рисунке четыре угла при пересечении прямых. Один угол \(35^\circ\). Запиши все четыре угла по порядку.

# Блок 4. Углы плюс уравнение

1. Смежные углы равны \(4x\) и \(5x\). Найди \(x\) и оба угла.
2. Смежные углы равны \(x - 10^\circ\) и \(2x + 40^\circ\). Найди \(x\) и оба угла.
3. Один из углов при пересечении двух прямых равен \(2x + 10^\circ\), вертикальный ему равен \(70^\circ\). Найди \(x\).
