> Главный акцент: смежные углы складываются до \(180^\circ\), вертикальные углы равны. В неравенствах проверяем фразу "делю на минус - знак переворачивается".

# Блок 1. Неравенства

1. \(-6x \le -18 \Rightarrow x \ge 3\).
2. \(-3x > -6 \Rightarrow x < 2\).
3. \(-2x \ge 14 \Rightarrow x \le -7\).
4. \(-0{,}5x < -3 \Rightarrow x > 6\).

# Блок 2. Смежные углы

1. \(180^\circ - 40^\circ = 140^\circ\).
2. \(180^\circ - 128^\circ = 52^\circ\).
3. \(x + 2x = 180^\circ \Rightarrow 3x = 180^\circ \Rightarrow x = 60^\circ\). Углы: \(60^\circ\) и \(120^\circ\).
4. \(x + 10^\circ + 2x - 10^\circ = 180^\circ \Rightarrow 3x = 180^\circ \Rightarrow x = 60^\circ\). Углы: \(70^\circ\) и \(110^\circ\).

# Блок 3. Вертикальные углы

1. Второй вертикальный угол тоже \(68^\circ\).
2. Остальные углы: \(65^\circ\), \(115^\circ\), \(65^\circ\).
3. \(3x + 15^\circ = 90^\circ \Rightarrow 3x = 75^\circ \Rightarrow x = 25^\circ\).
4. Все четыре угла: \(35^\circ\), \(145^\circ\), \(35^\circ\), \(145^\circ\).

# Блок 4. Углы плюс уравнение

1. \(4x + 5x = 180^\circ \Rightarrow 9x = 180^\circ \Rightarrow x = 20^\circ\). Углы: \(80^\circ\) и \(100^\circ\).
2. \(x - 10^\circ + 2x + 40^\circ = 180^\circ \Rightarrow 3x + 30^\circ = 180^\circ \Rightarrow x = 50^\circ\). Углы: \(40^\circ\) и \(140^\circ\).
3. \(2x + 10^\circ = 70^\circ \Rightarrow 2x = 60^\circ \Rightarrow x = 30^\circ\).

# Блок 5. Алгебра

1. \((8a - 5b) - (3a - 2b) = 8a - 5b - 3a + 2b = 5a - 3b\).
2. \(7x^2 - 5x + x^2 + 3x = 8x^2 - 2x\).
3. \(5(x - 2) = 25 \Rightarrow x - 2 = 5 \Rightarrow x = 7\).
4. При \(x = 3\): \(4(x - 1) = 8\), \(4x - 1 = 11\). Не равны.

# Что считать успехом

- В неравенствах 1-4 знак перевёрнут во всех номерах.
- В смежных углах ребёнок каждый раз использует сумму \(180^\circ\).
- В вертикальных углах ребёнок каждый раз использует равенство.
- Задачи с \(x\) решены через уравнение, а не угадыванием.
