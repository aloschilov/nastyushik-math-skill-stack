# Где спряталась единственная важная ошибка

В вычислении \(51^2\) появилась строка

\[
50^2+1^2=2501.
\]

Но квадрат суммы содержит ещё две одинаковые части \(50\cdot1\):

\[
(50+1)^2=50^2+2\cdot50\cdot1+1^2=2601.
\]

Это тот же средний член \(2ab\), только теперь буквы превратились в числа. Значит, формула уже понятна в буквенной записи, но её ещё нужно научиться узнавать в новом виде.

Для контрпримера \(x=2\) идея выбрана удачно. В следующий раз допиши значения обеих сторон: контрпример становится доказательством ошибки только после явного несовпадения чисел.
