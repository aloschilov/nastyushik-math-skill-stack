# Как помогать

Если ребёнок снова говорит, что \(a\) и \(b\) должны отличаться, не сообщать готовый ответ. Спросить:

> Какое именно условие задачи запрещает подставить \(a=1\) и \(b=1\)?

Если обрывается общая сумма, попросить выписать только три строки: первую, следующую и последнюю. После этого спросить, какой квадрат встречается сначала со знаком плюс, а затем со знаком минус.

# Критерий перехода

Можно закрыть коррекционный день, если ребёнок:

- допускает равные значения разных переменных без специального запрета;
- выводит общую сумму из строк для \(k=m,m+1,\ldots,n-1\);
- получает \(7500\) двумя независимыми способами;
- узнаёт разность квадратов в новом уравнении;
- завершает доказательство делимости через чётность произведения \(k(k+1)\).

После этого основной предмет следующего дня стоит переключить на геометрию.
