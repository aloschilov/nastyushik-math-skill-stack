> Короткий источник: [«Переменная»](https://interneturok.ru/glossariy/matematika/glossary_termin_3833.html). Прочитай только определение, это займёт меньше минуты.

В обычной алгебре разные буквы могут принимать одинаковые значения. Запрет появляется только из условия, например \(a\ne b\). Специальное правило «разные буквы означают разные цифры» иногда встречается в числовых ребусах, но само по себе в алгебру не переносится.

# Блок 1. Контрпример зависит от условия

Рассмотрим утверждение:

> Для любых положительных целых \(a\) и \(b\) выполняется \((a+b)^2=a^2+b^2\).

1. Разрешена ли условием пара \(a=1\), \(b=1\)? Обоснуй ответ словами из условия.
2. Подставь эту пару и реши, является ли она контрпримером.
3. Используй уже доказанное равенство

\[
(a+b)^2-(a^2+b^2)=2ab
\]

и докажи, что исходное равенство не выполняется ни для одной пары положительных целых \(a\) и \(b\).

\medskip

4. Добавим условие \(a\ne b\). Найди контрпример с наименьшей суммой \(a+b\). Если вариантов несколько, выбери вариант с меньшим \(a\). Докажи минимальность.

# Блок 2. Один шаг превращается в цепочку

Для любого целого \(k\):

\[
2k+1=(k+1)^2-k^2.
\]

Если последовательно подставить \(k=m,m+1,\ldots,n-1\), получаются первая, вторая и последняя строки:

\[
\begin{aligned}
2m+1&=(m+1)^2-m^2,\\
2m+3&=(m+2)^2-(m+1)^2,\\
&\ \vdots\\
2n-1&=n^2-(n-1)^2.
\end{aligned}
\]

1. Сложи эти равенства. Явно назови сокращающиеся квадраты и получи формулу всей суммы.
2. Примени формулу к сумме

\[
101+103+\ldots+199.
\]

3. Проверь ответ независимо: найди число членов и среднее первого и последнего членов, затем перемножь их.
4. Восстанови границы цепочки, если после сокращения осталось

\[
15^2-8^2.
\]

Запиши первый член, последний член, число членов и сумму.

# Блок 3. Разность квадратов выбирает способ

1. Разложи на множители:

\[
49x^2-16.
\]

2. Реши без полного раскрытия скобок:

\[
(3x-2)(3x+2)=77.
\]

Проверь оба найденных значения подстановкой.

3. Докажи, что у уравнения

\[
(x-5)(x+5)=72
\]

нет целых решений. Используй расположение числа \(97\) между двумя соседними квадратами.

4. Необязательный перенос. Найди целое \(n\), если

\[
n^2-(n-2)^2=100.
\]

# Блок 4. Разбор ответа «не знаю»

Пусть \(N\) - нечётное целое число. Тогда \(N=2k+1\), и

\[
\begin{aligned}
N^2-1
&=(N-1)(N+1)\\
&=2k(2k+2)\\
&=4k(k+1).
\end{aligned}
\]

Числа \(k\) и \(k+1\) последовательные, поэтому одно из них чётно. Значит, существует целое \(q\), для которого

\[
k(k+1)=2q.
\]

1. Подставь \(2q\) вместо \(k(k+1)\) и закончи доказательство делимости \(N^2-1\) на \(8\).
2. Не вычисляя \(37^2\), найди частное

\[
\frac{37^2-1}{8}.
\]

3. Перенеси идею: докажи, что произведение двух последовательных чётных чисел делится на \(8\).
