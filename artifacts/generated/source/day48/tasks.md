# Блок 1. Неравенства: десятичный минус

> Перед ответом напиши коротко: "делю на минус" или "делю не на минус".

1. \(-0{,}5x < -4\)
2. \(-0{,}25x \ge -2\)
3. \(-2x < 10\)
4. \(0{,}5x \le 3\)

# Блок 2. Новый образец

Разбери образец и перепиши его в тетрадь:

\[
2x(3x + 5) = 2x \cdot 3x + 2x \cdot 5 = 6x^2 + 10x.
\]

Теперь сделай сама:

1. \(2(3x + 5)\)
2. \(3x(x + 4)\)
3. \(-2(5a - 3)\)
4. \(-x(7x - 2)\)
5. \(0{,}5x(6x + 8)\)
6. \(-3a(2a - 5)\)

# Блок 3. Умножить и собрать подобные
