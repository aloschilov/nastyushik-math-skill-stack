> Главный акцент: при умножении одночлена на многочлен множитель распределяется на каждое слагаемое. В неравенствах отдельно проверяем десятичный отрицательный коэффициент.

# Блок 1. Неравенства

1. \(-0{,}5x < -4 \Rightarrow x > 8\).
2. \(-0{,}25x \ge -2 \Rightarrow x \le 8\).
3. \(-2x < 10 \Rightarrow x > -5\).
4. \(0{,}5x \le 3 \Rightarrow x \le 6\).

# Блок 2. Умножение одночлена на многочлен

1. \(2(3x + 5) = 6x + 10\).
2. \(3x(x + 4) = 3x^2 + 12x\).
3. \(-2(5a - 3) = -10a + 6\).
4. \(-x(7x - 2) = -7x^2 + 2x\).
5. \(0{,}5x(6x + 8) = 3x^2 + 4x\).
6. \(-3a(2a - 5) = -6a^2 + 15a\).

# Блок 3. Умножить и собрать подобные

1. \(2(x + 3) + 5x = 2x + 6 + 5x = 7x + 6\).
2. \(3a(2a - 1) - a^2 = 6a^2 - 3a - a^2 = 5a^2 - 3a\).
3. \(-2x(x - 4) + 3x^2 = -2x^2 + 8x + 3x^2 = x^2 + 8x\).
4. \(0{,}5m(4m - 6) + m = 2m^2 - 3m + m = 2m^2 - 2m\).

# Блок 4. Углы

1. Остальные углы: \(130^\circ\), \(50^\circ\), \(130^\circ\).
2. \(3x + 2x + 30^\circ = 180^\circ \Rightarrow 5x = 150^\circ \Rightarrow x = 30^\circ\). Углы: \(90^\circ\) и \(90^\circ\).
3. \(4x - 10^\circ = 70^\circ \Rightarrow 4x = 80^\circ \Rightarrow x = 20^\circ\).

# Что считать успехом

- В примерах 1-3 блока неравенств знак перевёрнут, потому что делим на отрицательное число.
- В примере 4 блока неравенств знак не перевёрнут, потому что делим на положительное число.
- В умножении скобок каждый член внутри скобки получил внешний множитель.
- В задачах с углами ребёнок сам выбирает: смежные дают \(180^\circ\), вертикальные равны.
