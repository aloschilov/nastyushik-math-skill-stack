> Главный акцент: буквенная часть внешнего множителя входит в каждое произведение. В неравенствах проговариваем, на положительное или отрицательное число делим.

# Блок 1. Буква не исчезает

1. \(0{,}5m \cdot 4m = 2m^2\).
2. \(0{,}5m \cdot 6 = 3m\).
3. \(-0{,}5x \cdot 6x = -3x^2\).
4. \(-0{,}5x \cdot (-2) = x\).
5. \(-2x \cdot (-3) = 6x\).
6. \(0{,}25p \cdot 8p = 2p^2\).

# Блок 2. Раскрыть скобки

1. \(0{,}5m(4m - 6) = 0{,}5m \cdot 4m - 0{,}5m \cdot 6 = 2m^2 - 3m\).
2. \(-0{,}5x(6x - 2) = -0{,}5x \cdot 6x + (-0{,}5x) \cdot (-2) = -3x^2 + x\).
3. \(-2x(x - 3) = -2x^2 + 6x\).
4. \(0{,}25p(8p + 4) = 2p^2 + p\).
5. \(-3a(2a - 5) = -6a^2 + 15a\).

# Блок 3. Раскрыть и собрать подобные

1. \(0{,}5m(4m - 6) + m = 2m^2 - 3m + m = 2m^2 - 2m\).
2. \(-0{,}5x(6x - 2) + 2x = -3x^2 + x + 2x = -3x^2 + 3x\).
3. \(-2x(x - 3) + x^2 = -2x^2 + 6x + x^2 = -x^2 + 6x\).
4. \(0{,}25p(8p + 4) - p = 2p^2 + p - p = 2p^2\).

# Блок 4. Неравенства

1. \(-0{,}25x > 1 \Rightarrow x < -4\).
2. \(0{,}2x < -1 \Rightarrow x < -5\).
3. \(-4x \ge 12 \Rightarrow x \le -3\).
4. \(-0{,}5x \le -5 \Rightarrow x \ge 10\).
5. \(0{,}5x \ge -3 \Rightarrow x \ge -6\).

# Блок 5. Геометрия

1. \(180^\circ - 65^\circ = 115^\circ\).
2. Остальные углы: \(140^\circ\), \(40^\circ\), \(140^\circ\).
3. \(3x + 20^\circ = 80^\circ \Rightarrow 3x = 60^\circ \Rightarrow x = 20^\circ\).

# Что считать успехом

- В \(0{,}5m \cdot 6\) получено \(3m\), не просто \(3\).
- В \(-2x(x - 3)\) получено \(-2x^2 + 6x\), не \(-2x^2 + 6\).
- В неравенствах 1, 3, 4 знак перевёрнут, потому что делим на отрицательное число.
- В неравенствах 2 и 5 знак не перевёрнут, потому что делим на положительное число.
