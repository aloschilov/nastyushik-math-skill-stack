> Видео дня: новое видео не нужно.
>
> Две команды дня: буква снаружи скобки умножает каждое слагаемое; если делим неравенство на отрицательное число, знак переворачивается.

# Блок 1. Буква не исчезает

Заполни пропуски.

1. \(0{,}5m \cdot 4m =\)
2. \(0{,}5m \cdot 6 =\)
3. \(-0{,}5x \cdot 6x =\)
4. \(-0{,}5x \cdot (-2) =\)
5. \(-2x \cdot (-3) =\)
6. \(0{,}25p \cdot 8p =\)

# Блок 2. Раскрой скобки по шагам

В каждом номере сначала напиши два произведения.

1. \(0{,}5m(4m - 6)\)
2. \(-0{,}5x(6x - 2)\)
3. \(-2x(x - 3)\)
4. \(0{,}25p(8p + 4)\)
5. \(-3a(2a - 5)\)

# Блок 3. Раскрой и собери подобные

1. \(0{,}5m(4m - 6) + m\)
2. \(-0{,}5x(6x - 2) + 2x\)
3. \(-2x(x - 3) + x^2\)
4. \(0{,}25p(8p + 4) - p\)

# Блок 4. Неравенства: куда смотрит знак

Перед ответом напиши: "делю на плюс" или "делю на минус".

1. \(-0{,}25x > 1\)
2. \(0{,}2x < -1\)
3. \(-4x \ge 12\)
4. \(-0{,}5x \le -5\)
5. \(0{,}5x \ge -3\)

# Блок 5. Геометрия на поддержание

1. Один из смежных углов равен \(65^\circ\). Найди второй.
2. При пересечении двух прямых один угол равен \(40^\circ\). Найди остальные три угла.
3. Вертикальные углы равны \(3x + 20^\circ\) и \(80^\circ\). Найди \(x\).

Вопрос в конце: где сегодня было легче ошибиться - в букве или в знаке неравенства?
