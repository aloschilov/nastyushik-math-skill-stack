> Видео дня: новое видео не нужно.
>
> Команда дня: общий множитель должен быть в каждом слагаемом. Если буквы нет в одном слагаемом, букву не выносим.

# Блок 1. Что можно вынести?

В каждом номере напиши общий множитель.

1. У \(6x^2\), \(9x\), \(3\)
2. У \(8a^2\), \(12a\), \(4a\)
3. У \(10m^2\), \(5m\), \(15\)
4. У \(0{,}5x^2\), \(1{,}5x\), \(0{,}5x\)
5. У \(-6p^2\) и \(-9p\)

# Блок 2. Вынеси общий множитель

1. \(6x^2 + 9x + 3\)
2. \(8a^2 + 12a + 4a\)
3. \(10m^2 + 5m - 15\)
4. \(0{,}5x^2 + 1{,}5x + 0{,}5x\)

# Блок 3. Вынеси отрицательный общий множитель

1. \(-6p^2 - 9p\)
2. \(-4a^2 + 8a\)
3. \(-10m^2 - 5m\)

# Блок 4. Проверь раскрытием

Раскрой скобки и убедись, что вернулся исходный многочлен.

1. \(3(2x^2 + 3x + 1)\)
2. \(4a(2a + 3 + 1)\)
3. \(-3p(2p + 3)\)

# Блок 5. Старый навык: строгий знак

1. \(-3x < 12\)
2. Подходит ли \(x = -4\) для условия \(x > -4\)?
3. Подходит ли \(x = -4\) для условия \(x \ge -4\)?

# Блок 6. Геометрия на поддержание

1. Один из смежных углов равен \(58^\circ\). Найди второй.
2. При пересечении двух прямых один угол равен \(140^\circ\). Найди остальные три угла.
