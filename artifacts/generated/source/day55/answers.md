> Главный акцент: общий множитель должен делить каждое слагаемое. Если хотя бы в одном слагаемом нет буквы, эту букву не выносим.

# Блок 1. Что можно вынести?

1. \(3\).
2. \(4a\).
3. \(5\).
4. \(0{,}5x\).
5. Можно вынести \(-3p\).

# Блок 2. Вынести общий множитель

1. \(6x^2 + 9x + 3 = 3(2x^2 + 3x + 1)\).
2. \(8a^2 + 12a + 4a = 4a(2a + 3 + 1)\). Можно также упростить внутри: \(4a(2a + 4)\).
3. \(10m^2 + 5m - 15 = 5(2m^2 + m - 3)\).
4. \(0{,}5x^2 + 1{,}5x + 0{,}5x = 0{,}5x(x + 3 + 1)\). Можно также \(0{,}5x(x + 4)\).

# Блок 3. Отрицательный общий множитель

1. \(-6p^2 - 9p = -3p(2p + 3)\).
2. \(-4a^2 + 8a = -4a(a - 2)\).
3. \(-10m^2 - 5m = -5m(2m + 1)\).

# Блок 4. Проверить раскрытием

1. \(3(2x^2 + 3x + 1) = 6x^2 + 9x + 3\).
2. \(4a(2a + 3 + 1) = 8a^2 + 12a + 4a\).
3. \(-3p(2p + 3) = -6p^2 - 9p\).

# Блок 5. Строгий знак

1. \(-3x < 12 \Rightarrow x > -4\). Знак строгий, поэтому черта под знаком не появляется.
2. Не подходит: \(-4\) не больше \(-4\).
3. Подходит: \(-4\) равно \(-4\), а знак \(\ge\) разрешает равенство.

# Блок 6. Геометрия

1. \(180^\circ - 58^\circ = 122^\circ\).
2. Вертикальный угол равен \(140^\circ\). Два смежных угла равны \(180^\circ - 140^\circ = 40^\circ\). Остальные три угла: \(140^\circ\), \(40^\circ\), \(40^\circ\).

# Что считать успехом

- В блоке 1 буква вынесена только там, где она есть во всех слагаемых.
- В блоке 3 отрицательный общий множитель раскрывается обратно без потери знака.
- В неравенстве \(-3x < 12\) ответ строгий: \(x > -4\).
