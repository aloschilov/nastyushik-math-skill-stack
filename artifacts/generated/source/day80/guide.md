# Одни числа, два расположения

Пусть \(OP\) - исходный луч, \(OR\) образует с ним угол \(20^\circ\), а \(OS\) - угол \(50^\circ\).

- Если \(OR\) и \(OS\) находятся **в одной** полуплоскости относительно \(OP\), меньший угол между ними равен \(50^\circ-20^\circ=30^\circ\).
- Если они находятся **в разных** полуплоскостях, \(OP\) проходит внутри меньшего угла между ними, и он равен \(20^\circ+50^\circ=70^\circ\).

Числа не изменились. Изменилось расположение, поэтому изменился способ получить \(\angle ROS\).

# Как проверять контрпример

Сначала выпиши все условия исходного утверждения. Если вычеркнули только условие о разных полуплоскостях, новый рисунок может нарушать **только его**. В частности, величины углов, общее начало и исходный луч должны остаться прежними. После построения посчитай именно тот угол, который отвечает за вывод.

# Почему «ровно два» относится к любому углу

Аксиома откладывания говорит о любом заранее выбранном \(\alpha\), для которого \(0^\circ<\alpha<180^\circ\). В каждой полуплоскости она даёт одного подходящего кандидата; третьего внутри этих полуплоскостей не бывает. На границе угол мог бы быть лишь \(0^\circ\) или \(180^\circ\), поэтому граница тоже не даёт третьего. Это и есть общий довод, а не проверка одной величины.
