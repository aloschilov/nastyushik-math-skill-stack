# 1. Условие и заключение

Утверждение обычно читается так:

> Если выполнено **условие**, то верно **заключение**.

Например:

> Если два угла вертикальные, то они равны.

Условие: углы вертикальные. Заключение: углы равны.

Переставить части местами - значит получить обратное утверждение:

> Если два угла равны, то они вертикальные.

Оно неверно: на рисунке можно построить два равных угла с разными вершинами. Поэтому верная теорема не делает обратное утверждение автоматически верным.

# 2. Четыре разные роли

**Определение** сообщает, что означает новое понятие. Биссектриса угла - луч, который выходит из вершины и делит угол на два равных угла.

Если \(OC\) - биссектриса угла \(AOB\), то по определению

\[
\angle AOC=\angle COB.
\]

**Аксиома** - исходное утверждение, принятое без доказательства. Для углов используется правило сложения: если луч \(OC\) проходит внутри угла \(AOB\), то

\[
\angle AOB=\angle AOC+\angle COB.
\]

**Теорема** - утверждение, которое следует доказать из определений, аксиом и уже известных теорем.

**Признак** работает в направлении распознавания. Например, если внутренний луч делит угол на два равных угла, то этот луч является биссектрисой по определению.

# 3. Как доказываются вертикальные углы

Пусть прямые \(AB\) и \(CD\) пересекаются в точке \(O\). Докажем:

\[
\angle AOC=\angle BOD.
\]

Угол \(COB\) смежный с каждым из них. Поэтому

\[
\angle AOC+\angle COB=180^\circ,
\]

\[
\angle BOD+\angle COB=180^\circ.
\]

Левые части равны одному и тому же числу. Вычтем из обеих частей общий угол \(COB\):

\[
\angle AOC=\angle BOD.
\]

Рисунок подсказал, какой угол общий. Само равенство получено не «по виду», а из двух сумм и допустимого вычитания.

# 4. Каркас полного решения

1. Запиши, что дано.
2. Запиши, что требуется доказать.
3. Для каждого перехода назови основание.
4. Проверь, не используешь ли ты заключение раньше, чем доказала его.
5. Проверь обратное утверждение отдельно: оно может оказаться ложным.

# Короткая самопроверка

Если \(OC\) - биссектриса угла \(AOB\), а \(\angle AOB=74^\circ\), то

\[
\angle AOC=\angle COB=37^\circ.
\]

Здесь равенство двух частей взято из определения, а их сумма \(74^\circ\) - из сложения углов.
