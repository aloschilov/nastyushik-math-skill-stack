> Сначала прочитай пособие и посмотри указанные в нём два раздела источника. В решении после каждой существенной строки коротко пиши основание: «по определению», «смежные углы», «вычитаю равные величины» или «контрпример».

# Блок 1. Разобрать утверждение, а не термин

Дано утверждение:

> Если два угла вертикальные, то они равны.

1. Запиши отдельно условие и заключение.
2. Сформулируй обратное утверждение.
3. Определи, верно ли обратное утверждение. Если нет, нарисуй конкретный контрпример: два равных угла, которые не являются вертикальными.
4. Объясни, почему один такой рисунок достаточен для опровержения обратного утверждения, но рисунок с вертикальными углами не доказывает исходную теорему.

# Блок 2. Собрать доказательство вертикальных углов

Прямые \(AB\) и \(CD\) пересекаются в точке \(O\). Нужно доказать:

\[
\angle AOC=\angle BOD.
\]

1. Нарисуй конфигурацию и отметь общий смежный угол \(COB\).
2. Запиши две суммы, каждая из которых равна \(180^\circ\).
3. Из двух равенств получи требуемое равенство углов. Назови действие, которое убирает общий угол.
4. Проверь доказательство: использовала ли ты где-нибудь равенство вертикальных углов до того, как получила его?

# Блок 3. Определение как инструмент

Луч \(OC\) проходит внутри угла \(AOB\). Известно, что

\[
\angle AOC=(3x+7)^\circ,
\]

\[
\angle COB=(5x-19)^\circ,
\]

а \(OC\) - биссектриса угла \(AOB\).

1. Объясни, какое равенство разрешено записать именно по определению биссектрисы.
2. Найди \(x\) и величины обоих углов.
3. Найди \(\angle AOB\).
4. Убери из условия слова «\(OC\) - биссектриса» и оставь только найденное числовое равенство двух внутренних углов. Достаточно ли этого, чтобы восстановить вывод о биссектрисе? Обоснуй по определению.

# Блок 4. Проверить возможный рисунок аксиомой

Для каждого набора выясни, может ли луч \(OC\) проходить внутри угла \(AOB\).

**Набор A:**

\[
\angle AOB=132^\circ,
\quad
\angle AOC=47^\circ,
\quad
\angle COB=85^\circ.
\]

**Набор B:**

\[
\angle AOB=120^\circ,
\quad
\angle AOC=50^\circ,
\quad
\angle COB=80^\circ.
\]

1. Для каждого набора запиши необходимое равенство из правила сложения углов.
2. Сделай вывод о возможности конфигурации.
3. Объясни, почему аккуратно нарисованная картинка не может исправить набор, нарушающий равенство.

# Блок 5. Цепочка «наблюдение - гипотеза - доказательство - применение»

Нарисуй две пересекающиеся прямые и проведи биссектрисы двух вертикальных углов.

1. **Наблюдение.** Что ты замечаешь о двух биссектрисах?
2. **Гипотеза.** Сформулируй точное утверждение.
3. **Доказательство.** Обозначь один вертикальный угол через \(2\alpha\). Найди половины обоих вертикальных углов и объясни, почему биссектрисы лежат на одной прямой.
4. **Применение.** Если один из вертикальных углов равен \(86^\circ\), найди четыре угла, на которые биссектрисы разделили эту пару вертикальных углов.

# Необязательный олимпиадный перенос

Угол \(AOB\) равен \(120^\circ\). Внутри него проведены лучи \(OC\) и \(OD\), причём

\[
\angle AOC=\angle DOB=35^\circ.
\]

Докажи, что биссектриса угла \(COD\) одновременно является биссектрисой угла \(AOB\). Постарайся решить без транспортира.
