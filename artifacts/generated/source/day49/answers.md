> Главный акцент: после раскрытия скобок сохраняем знак следующего слагаемого. В десятичных коэффициентах сначала перемножаем числа, потом буквенную часть.

# Блок 1. Ловушки

1. \(180^\circ - 50^\circ = 130^\circ\).
2. \(180^\circ - 70^\circ = 110^\circ\).
3. \(0{,}5m \cdot 4m = 2m^2\).
4. \(0{,}25x \cdot 8x = 2x^2\).
5. \(2(x + 3) + 5x = 2x + 6 + 5x = 7x + 6\).

# Блок 2. Раскрыть скобки

1. \(2x(4x + 3) = 8x^2 + 6x\).
2. \(-3a(2a + 5) = -6a^2 - 15a\).
3. \(0{,}5m(4m - 6) = 2m^2 - 3m\).
4. \(-0{,}5x(6x - 2) = -3x^2 + x\).
5. \(0{,}25p(8p + 4) = 2p^2 + p\).
6. \(-y(5y - 7) = -5y^2 + 7y\).

# Блок 3. Раскрыть и собрать подобные

1. \(2(x + 3) + 5x = 7x + 6\).
2. \(3a(a + 2) - 4a = 3a^2 + 6a - 4a = 3a^2 + 2a\).
3. \(0{,}5m(4m - 6) + m = 2m^2 - 3m + m = 2m^2 - 2m\).
4. \(-2x(x - 3) + x^2 = -2x^2 + 6x + x^2 = -x^2 + 6x\).
5. \(-0{,}5p(8p + 2) + 3p = -4p^2 - p + 3p = -4p^2 + 2p\).

# Блок 4. Неравенства

1. \(-0{,}5x \le -5 \Rightarrow x \ge 10\).
2. \(-0{,}25x > 1 \Rightarrow x < -4\).
3. \(0{,}2x < -1 \Rightarrow x < -5\).
4. \(-4x \ge 12 \Rightarrow x \le -3\).

# Блок 5. Углы

1. Остальные углы: \(130^\circ\), \(50^\circ\), \(130^\circ\).
2. \(180^\circ - 70^\circ = 110^\circ\).
3. \(5x + 10^\circ = 110^\circ \Rightarrow 5x = 100^\circ \Rightarrow x = 20^\circ\).

# Что считать успехом

- В \(2(x + 3) + 5x\) знак \(+5x\) сохранился.
- В \(0{,}5m \cdot 4m\) получено \(2m^2\).
- В геометрии ребёнок пишет \(180^\circ - 50^\circ = 130^\circ\), без потери сотни.
- В неравенствах с отрицательным коэффициентом знак переворачивается.
