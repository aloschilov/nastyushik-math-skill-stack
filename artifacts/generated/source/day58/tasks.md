> Посмотри правило и первый полностью разобранный пример. На сегодня достаточно 8-10 минут.

> Команда дня: каждое слагаемое первой скобки умножаем на каждое слагаемое второй. Для двух слагаемых в каждой скобке получаем четыре произведения.

# Блок 1. Четыре произведения

Для \((x+2)(x+3)\) заполни четыре шага.

1. \(x\cdot x=\ ?\)
2. \(x\cdot3=\ ?\)
3. \(2\cdot x=\ ?\)
4. \(2\cdot3=\ ?\)

Теперь сложи результаты и приведи подобные слагаемые.

# Блок 2. Раскрой скобки

Сначала запиши четыре произведения, затем собери подобные.

1. \((a+1)(a+4)\)
2. \((m+2)(m+5)\)
3. \((p+3)(p-2)\)

# Блок 3. Проверь подстановкой

Для \((x+2)(x+3)\) подставь \(x=1\) в исходное выражение и в полученный многочлен. Сравни результаты.

# Блок 4. Старый навык: неравенства

1. \(-5x<15\)
2. \(2-4x\ge10\)

# Блок 5. Геометрия на поддержание

1. Один из смежных углов равен \(71^\circ\). Найди второй.
2. При пересечении двух прямых один угол равен \(112^\circ\). Найди остальные три угла.

Вопрос в конце: почему при умножении двух двучленов сначала получается именно четыре произведения?
