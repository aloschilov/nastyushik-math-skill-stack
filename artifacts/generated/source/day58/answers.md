> Главный акцент: четыре произведения должны быть записаны до приведения подобных. На первом дне важнее полнота распределения, чем скорость.

# Блок 1. Четыре произведения

1. \(x\cdot x=x^2\).
2. \(x\cdot3=3x\).
3. \(2\cdot x=2x\).
4. \(2\cdot3=6\).

Итог:

\[
(x+2)(x+3)=x^2+3x+2x+6=x^2+5x+6.
\]

# Блок 2. Раскрыть скобки

1. \((a+1)(a+4)=a^2+4a+a+4=a^2+5a+4\).
2. \((m+2)(m+5)=m^2+5m+2m+10=m^2+7m+10\).
3. \((p+3)(p-2)=p^2-2p+3p-6=p^2+p-6\).

# Блок 3. Проверить подстановкой

При \(x=1\):

\[
(1+2)(1+3)=3\cdot4=12,
\]

\[
1^2+5\cdot1+6=12.
\]

Результаты совпали.

# Блок 4. Неравенства

1. \(-5x<15\Rightarrow x>-3\).
2. \(2-4x\ge10\Rightarrow -4x\ge8\Rightarrow x\le-2\).

# Блок 5. Геометрия

1. \(180^\circ-71^\circ=109^\circ\).
2. Вертикальный угол равен \(112^\circ\). Два смежных угла равны \(180^\circ-112^\circ=68^\circ\). Ответ: \(112^\circ\), \(68^\circ\), \(68^\circ\).

# Что считать успехом

- В каждом произведении двучленов записаны все четыре произведения.
- Подобные слагаемые собраны только после раскрытия обеих скобок.
- В примере с минусом правильно получено \(-6\).
