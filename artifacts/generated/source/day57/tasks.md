> Видео дня: новое видео не нужно.
>
> Команда дня: перед ответом молча проверь две вещи. Делила ли ты на отрицательное число? Был ли исходный знак строгим?

# Блок 1. Реши самостоятельно

Подписи «развернуть / оставить» больше не обязательны.

1. \(-6x < 18\)
2. \(4x \ge -20\)
3. \(-0{,}4x \le 2\)
4. \(0{,}25x > -1\)
5. \(5 - 3x \ge 14\)

# Блок 2. Найди и исправь ошибку

В каждом решении назови ошибку: направление или строгость. Затем запиши правильный ответ.

1. \(-2x < 8 \Rightarrow x \ge -4\)
2. \(-3x \le 12 \Rightarrow x \le -4\)
3. \(4x > -8 \Rightarrow x < -2\)

# Блок 3. Проверь границу

1. Подходит ли \(x=-3\) для ответа \(x\le-3\)?
2. Подходит ли \(x=-4\) для ответа \(x>-4\)?

# Блок 4. Выбери действие сама

Если скобки есть, раскрой их. Если скобок нет, вынеси общий множитель.

1. \(5(2x-3)\)
2. \(12a^2-8a\)
3. \(-3m(m+4)\)
4. \(-9p^2+6p\)

# Блок 5. Геометрия на поддержание

1. Один из смежных углов равен \(64^\circ\). Найди второй.
2. При пересечении двух прямых один угол равен \(106^\circ\). Найди остальные три угла.

Вопрос в конце: закончи две фразы. «При делении на отрицательное число направление знака ... . Строгость знака ... .»
