> Главный акцент: после успешного дня с письменными метками проверяем перенос без внешней опоры. Направление и строгость по-прежнему контролируются отдельно.

# Блок 1. Решить самостоятельно

1. \(-6x < 18 \Rightarrow x>-3\).
2. \(4x \ge -20 \Rightarrow x\ge-5\).
3. \(-0{,}4x \le 2 \Rightarrow x\ge-5\).
4. \(0{,}25x > -1 \Rightarrow x>-4\).
5. \(5-3x\ge14 \Rightarrow -3x\ge9 \Rightarrow x\le-3\).

# Блок 2. Исправить ошибку

1. Направление выбрано верно, но потеряна строгость. Правильно: \(x>-4\).
2. Строгость сохранена, но направление не развёрнуто. Правильно: \(x\ge-4\).
3. При делении на положительное число направление менять нельзя. Правильно: \(x>-2\).

# Блок 3. Проверить границу

1. Да: знак \(\le\) разрешает равенство.
2. Нет: \(-4\) не больше \(-4\).

# Блок 4. Выбрать действие

1. \(5(2x-3)=10x-15\).
2. \(12a^2-8a=4a(3a-2)\).
3. \(-3m(m+4)=-3m^2-12m\).
4. \(-9p^2+6p=-3p(3p-2)\).

# Блок 5. Геометрия

1. \(180^\circ-64^\circ=116^\circ\).
2. Вертикальный угол равен \(106^\circ\). Два смежных угла равны \(180^\circ-106^\circ=74^\circ\). Ответ: \(106^\circ\), \(74^\circ\), \(74^\circ\).

# Ответ на вопрос дня

При делении на отрицательное число направление знака меняется. Строгость знака не меняется.

# Что считать успехом

- Не менее четырёх из пяти неравенств решены без письменной подсказки.
- В блоке 2 правильно названы направление и строгость.
- В смешанном блоке действие выбрано по виду выражения.
