> Разрешённый инструмент:
\[
(kx)^2=(kx)(kx)=k^2x^2.
\]

# Блок 1. Три конкурирующие гипотезы

Три человека предложили формулу для \((2x+5)^2\):

\[
\text{А: }2x^2+20x+25,\qquad
\text{Б: }4x^2+10x+25,\qquad
\text{В: }4x^2+20x+25.
\]

1. Выбери формулу, которая может быть тождеством.
2. Обоснуй выбор через произведение \((2x)(2x)\), не раскрывая всё выражение.
3. Найди одно значение \(x\), которое сразу опровергает обе неверные формулы.
4. Объясни, почему значение \(x=0\) здесь бесполезно.

# Блок 2. Обратная задача

1. Найди положительное число \(c\), при котором \(9x^2+cx+16=(3x+4)^2\) является тождеством.

2. Может ли многочлен \(9x^2+20x+16\) быть квадратом суммы \((ax+b)^2\), где \(a\) и \(b\) - положительные целые числа? Докажи ответ без перебора многих пар.

# Блок 3. Маленькое доказательство

Для целого \(n\ge0\) рассмотрим квадраты соседних чисел.

1. Раскрой только \((n+1)^2\) и докажи:

\[
(n+1)^2-n^2=2n+1.
\]

2. Почему разность квадратов соседних целых чисел всегда нечётна?
3. Представь \(39\) как разность квадратов двух соседних целых чисел.
4. Можно ли так представить \(40\)? Ответ обоснуй.

# Блок 4. Используй результат

Не вычисляя сами квадраты столбиком, найди:

1. \(1001^2-1000^2\);
2. \(51^2\), представив \(51\) как \(50+1\).
