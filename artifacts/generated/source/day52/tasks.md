# Блок 1. Только решение про знак

В каждом номере напиши одно слово: "перевернуть" или "оставить".

1. Делим обе части неравенства на \(-2\).
2. Делим обе части неравенства на \(0{,}5\).
3. Делим обе части неравенства на \(-0{,}25\).
4. Делим обе части неравенства на \(3\).
5. Делим обе части неравенства на \(-1\).
6. Делим обе части неравенства на \(0{,}2\).

# Блок 2. Реши парами

В каждом номере сначала подпиши делитель: \(+\) или \(-\).

1. \(-2x > 8\)
2. \(2x > 8\)
3. \(-0{,}25x > 1\)
4. \(0{,}25x > 1\)
5. \(-0{,}5x \le -5\)
6. \(0{,}5x \le -5\)

# Блок 3. Найди ошибку

Если запись верная, напиши "верно". Если неверная, исправь ответ.

1. \(-0{,}25x > 1 \Rightarrow x > -4\)
2. \(0{,}2x < -1 \Rightarrow x < -5\)
3. \(-4x \ge 12 \Rightarrow x \ge -3\)
4. \(0{,}5x \ge -3 \Rightarrow x \le -6\)
