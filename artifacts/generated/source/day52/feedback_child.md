# Что надо поправить

- В одном смешанном выражении с \(p\) знак второго слагаемого снова соскочил:
  \[
  -0{,}25p(8p - 4) + 3p = -2p^2 + p + 3p = -2p^2 + 4p.
  \]
  Там должно быть \(+p\), потому что \(-0{,}25p \cdot (-4) = +p\).
- Главная тема для исправления - неравенства. Сначала надо смотреть только на делитель. Если делим на отрицательное число, знак переворачивается. Если делим на положительное число, знак остаётся.
- Например:
  \[
  -0{,}25x > 1 \Rightarrow x < -4,
  \]
  потому что делим на \(-0{,}25\).
