> Главный акцент: направление знака в неравенстве зависит только от знака числа, на которое делим или умножаем обе части.

# Блок 1. Только решение про знак

1. Перевернуть.
2. Оставить.
3. Перевернуть.
4. Оставить.
5. Перевернуть.
6. Оставить.

# Блок 2. Решить парами

1. \(-2x > 8 \Rightarrow x < -4\).
2. \(2x > 8 \Rightarrow x > 4\).
3. \(-0{,}25x > 1 \Rightarrow x < -4\).
4. \(0{,}25x > 1 \Rightarrow x > 4\).
5. \(-0{,}5x \le -5 \Rightarrow x \ge 10\).
6. \(0{,}5x \le -5 \Rightarrow x \le -10\).

# Блок 3. Найти ошибку

1. Неверно: \(-0{,}25x > 1 \Rightarrow x < -4\), потому что делим на \(-0{,}25\).
2. Верно: \(0{,}2x < -1 \Rightarrow x < -5\), потому что делим на положительное число.
3. Неверно: \(-4x \ge 12 \Rightarrow x \le -3\), потому что делим на \(-4\).
4. Неверно: \(0{,}5x \ge -3 \Rightarrow x \ge -6\), потому что делим на положительное число.

# Блок 4. Алгебра

1. \(-0{,}25p(8p - 4) + 3p = -2p^2 + p + 3p = -2p^2 + 4p\).
2. \(-0{,}5x(6x - 2) + x = -3x^2 + x + x = -3x^2 + 2x\).
3. \(-3a(2a - 5) - 2a = -6a^2 + 15a - 2a = -6a^2 + 13a\).
4. \(0{,}5m(4m - 6) + 2m = 2m^2 - 3m + 2m = 2m^2 - m\).

# Блок 5. Геометрия

1. \(\angle 2 = 180^\circ - 70^\circ = 110^\circ\).
2. \(5x - 10^\circ = 90^\circ \Rightarrow 5x = 100^\circ \Rightarrow x = 20^\circ\).

# Что считать успехом

- В блоке 1 все отрицательные делители помечены как "перевернуть", а положительные как "оставить".
- В блоке 2 пары \(1\) и \(2\), \(3\) и \(4\), \(5\) и \(6\) различаются только знаком делителя.
- В блоке 3 ребёнок исправляет направление знака словами, а не угадывает итог.
- В алгебре пример с \(p\) даёт \(+p\), а не \(-p\).
