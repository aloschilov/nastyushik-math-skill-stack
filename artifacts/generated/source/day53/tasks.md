> Видео дня: новое видео не нужно.
>
> Команда дня: сначала знак делителя, потом строгость знака. Если делим на минус, направление меняется. Если знак был строгий, он остаётся строгим.

# Блок 1. Неравенства без парной подсказки

Сначала подпиши делитель: \(+\) или \(-\). Потом реши.

1. \(-3x < 12\)
2. \(4x \le -16\)
3. \(-0{,}5x \ge 2\)
4. \(0{,}25x > -2\)
5. \(-0{,}2x \le -1\)
6. \(5x \ge 15\)

# Блок 2. Два шага

Сначала перенеси число, потом раздели.

1. \(2x - 5 = 9\)
2. \(-2x + 3 > 11\)
3. \(0{,}5x + 2 \le 5\)
4. \(-0{,}25x - 1 \ge 2\)

# Блок 3. Строгий или нестрогий

Напиши "подходит" или "не подходит".

1. \(x = -4\) для условия \(x < -4\)
2. \(x = -4\) для условия \(x \le -4\)
3. \(x = 5\) для условия \(x \ge 5\)
4. \(x = 5\) для условия \(x > 5\)

# Блок 4. Алгебра на поддержание

Раскрой скобки и собери подобные.

1. \(-0{,}25p(8p - 4) + p\)
2. \(-0{,}5x(4x - 6) - 2x\)
3. \(2a(3a - 5) - a\)
4. \(-3m(2m - 1) + 4m\)

# Блок 5. Геометрия на поддержание

1. Один из смежных углов равен \(35^\circ\). Найди второй.
2. При пересечении двух прямых один угол равен \(120^\circ\). Найди остальные три угла.

Вопрос в конце: что сегодня легче - неравенства или раскрытие скобок?
