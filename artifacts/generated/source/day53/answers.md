> Главный акцент: проверяем перенос навыка. В неравенствах ребёнок должен сам найти знак делителя, даже когда рядом нет похожей пары.

# Блок 1. Неравенства без парной подсказки

1. \(-3x < 12 \Rightarrow x > -4\).
2. \(4x \le -16 \Rightarrow x \le -4\).
3. \(-0{,}5x \ge 2 \Rightarrow x \le -4\).
4. \(0{,}25x > -2 \Rightarrow x > -8\).
5. \(-0{,}2x \le -1 \Rightarrow x \ge 5\).
6. \(5x \ge 15 \Rightarrow x \ge 3\).

# Блок 2. Два шага

1. \(2x - 5 = 9 \Rightarrow 2x = 14 \Rightarrow x = 7\).
2. \(-2x + 3 > 11 \Rightarrow -2x > 8 \Rightarrow x < -4\).
3. \(0{,}5x + 2 \le 5 \Rightarrow 0{,}5x \le 3 \Rightarrow x \le 6\).
4. \(-0{,}25x - 1 \ge 2 \Rightarrow -0{,}25x \ge 3 \Rightarrow x \le -12\).

# Блок 3. Строгий или нестрогий

1. Не подходит: \(-4\) не меньше \(-4\).
2. Подходит: \(-4\) равно \(-4\), а знак \(\le\) разрешает равенство.
3. Подходит: \(5\) равно \(5\), а знак \(\ge\) разрешает равенство.
4. Не подходит: \(5\) не больше \(5\).

# Блок 4. Алгебра

1. \(-0{,}25p(8p - 4) + p = -2p^2 + p + p = -2p^2 + 2p\).
2. \(-0{,}5x(4x - 6) - 2x = -2x^2 + 3x - 2x = -2x^2 + x\).
3. \(2a(3a - 5) - a = 6a^2 - 10a - a = 6a^2 - 11a\).
4. \(-3m(2m - 1) + 4m = -6m^2 + 3m + 4m = -6m^2 + 7m\).

# Блок 5. Геометрия

1. \(180^\circ - 35^\circ = 145^\circ\).
2. Вертикальный угол равен \(120^\circ\). Два смежных угла равны \(180^\circ - 120^\circ = 60^\circ\). Остальные три угла: \(120^\circ\), \(60^\circ\), \(60^\circ\).

# Что считать успехом

- В блоке 1 знак меняется только при отрицательном делителе.
- В блоке 2 ребёнок не теряет второй шаг после переноса числа.
- В блоке 3 граничная точка отличает \(<\) от \(\le\) и \(>\) от \(\ge\).
- В блоке 4 знаки при раскрытии скобок удержаны без отдельной подсказки.
