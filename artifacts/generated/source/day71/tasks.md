# Блок 1. Две записи с числом \(2025\)

Сравни две задачи:

\[
S_1=1+3+5+\ldots+2025,
\]

\[
S_2=1+3+5+\ldots+(2r-1)=2025.
\]

1. Для каждой записи объясни словами роль числа \(2025\).
2. В первой записи найди число членов и значение \(S_1\).
3. Во второй записи найди \(r\) и последний член суммы.
4. Объясни, почему ответы \(1013\) и \(45\) относятся к разным вопросам и не противоречат друг другу.

# Блок 2. Сдвинуть правую границу

Не подставляя чисел вместо букв, восстанови правые части:

\[
(2m+1)+(2m+3)+\ldots+(2n-1)=\ ?
\]

\[
(2m+1)+(2m+3)+\ldots+(2n+1)=\ ?
\]

\[
(2m+1)+(2m+3)+\ldots+(2n+3)=\ ?
\]

Для каждой строки выпиши только последнюю разность квадратов и объясни, почему правый край сдвигается.

Проверь все три формулы на \(m=1\) и \(n=4\). Здесь проверка нужна для поиска собственной ошибки, а не вместо буквенного объяснения.

# Блок 3. Пример против утверждения

Рассмотри утверждение:

> Произведение любых двух последовательных чётных чисел делится на \(16\).

1. Найди одну пару, которая подтверждает утверждение.
2. Найди одну пару, которая его опровергает.
3. Объясни, почему первая пара не является доказательством, а второй пары достаточно для опровержения.
4. Сформулируй гарантированно верное утверждение о делимости на \(8\) и докажи его для произвольной пары \(2k\) и \(2k+2\).

# Блок 4. Восстановить сумму по двум условиям

Сумма состоит из \(12\) последовательных положительных нечётных чисел и равна \(720\).

**Два условия.** Пусть телескопическая запись суммы равна \(n^2-m^2\). Запиши отдельно уравнение, которое даёт число членов, и уравнение, которое даёт значение суммы.

**Разность квадратов.** Используй

\[
n^2-m^2=(n-m)(n+m)
\]

и найди \(m\) и \(n\).

**Границы.** Восстанови первый и последний члены суммы.

**Проверка.** Запиши сумму и проверь её через среднее и число членов.

# Необязательный олимпиадный перенос

Представь \(2025\) суммой последовательных положительных нечётных чисел двумя разными способами: сначала используя первые нечётные числа, затем так, чтобы слагаемых было ровно три. Объясни обе записи через разность квадратов.
