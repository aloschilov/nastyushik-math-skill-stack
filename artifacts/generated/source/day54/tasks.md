# Блок 1. Найди общий множитель

В каждом номере напиши общий множитель.

2. У \(4a^2\) и \(8a\)
3. У \(10m^2\) и \(5m\)
4. У \(12p^2\) и \(18p\)

4. \(-0{,}25x - 1 \ge 2\)
