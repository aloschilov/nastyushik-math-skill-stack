> Главный акцент: вынесение общего множителя проверяется обратным раскрытием скобок.

# Блок 1. Найти общий множитель

1. \(3x\).
2. \(4a\).
3. \(5m\).
4. \(6p\).
5. \(0{,}5x\).

# Блок 2. Вынести общий множитель

1. \(6x^2 + 9x = 3x(2x + 3)\).
2. \(4a^2 - 8a = 4a(a - 2)\).
3. \(10m^2 + 5m = 5m(2m + 1)\).
4. \(12p^2 - 18p = 6p(2p - 3)\).
5. \(0{,}5x^2 + 2x = 0{,}5x(x + 4)\).

# Блок 3. Проверить раскрытием

1. \(3x(2x + 3) = 6x^2 + 9x\).
2. \(4a(a - 2) = 4a^2 - 8a\).
3. \(5m(2m + 1) = 10m^2 + 5m\).
4. \(6p(2p - 3) = 12p^2 - 18p\).

# Блок 4. Неравенства

1. \(-3x < 12 \Rightarrow x > -4\). Знак строгий, поэтому черта под знаком не появляется.
2. Не подходит: \(-4\) не больше \(-4\).
3. \(-2x + 3 > 11 \Rightarrow -2x > 8 \Rightarrow x < -4\).
4. \(-0{,}25x - 1 \ge 2 \Rightarrow -0{,}25x \ge 3 \Rightarrow x \le -12\).

# Блок 5. Геометрия

1. \(180^\circ - 42^\circ = 138^\circ\).
2. Вертикальный угол равен \(130^\circ\). Два смежных угла равны \(180^\circ - 130^\circ = 50^\circ\). Остальные три угла: \(130^\circ\), \(50^\circ\), \(50^\circ\).

# Что считать успехом

- В блоке 2 общий множитель действительно есть в каждом слагаемом.
- В блоке 3 раскрытие скобок возвращает исходный многочлен.
- В неравенствах строгий знак остаётся строгим.
- В геометрии вертикальные углы равны, а смежные дают \(180^\circ\).
