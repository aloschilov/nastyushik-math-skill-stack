> Видео сегодня не обязательно. Если забылось правило четырёх произведений, открой [«Умножение двучленов. Типовые задачи»](https://interneturok.ru/h/biblioteka/algebra/7-klass/umnozhenie-dvuchlenov-tipovie-zadachi/1) и посмотри только первый разобранный пример, не более 5 минут.

> Команда дня: перед вычислением сравни свою первую строку с условием. Числа и буква должны совпасть.

# Блок 1. Точная копия

Перепиши каждое выражение на следующую строку без вычислений. Затем поставь галочку, если оба числа и буква совпали.

1. \((a+1)(a+5)\)
2. \((b+4)(b-2)\)
3. \((c-3)(c-2)\)

# Блок 2. Три произведения

Используй точные копии из Блока 1. Для каждого примера:

1. запиши четыре произведения;
2. собери только подобные слагаемые;
3. ещё раз сравни числа и букву с условием.

# Блок 3. Найди две подмены

Ученик начал решать:

\[
(y+2)(y+4)=y^2+4x+3x+8.
\]

1. Какая буква была подменена?
2. Какое число было подменено?
3. Запиши верное раскрытие скобок и итог.

# Блок 4. Быстрая проверка

Проверь подстановкой \(b=0\) свой результат для \((b+4)(b-2)\). Значения исходного выражения и многочлена должны совпасть.

# Блок 5. Старые навыки на поддержание

1. Реши неравенство: \(4-6x\ge16\).
2. При пересечении двух прямых \(\angle 1=63^\circ\). Нарисуй и подпиши \(\angle 1\), \(\angle 2\), \(\angle 3\), \(\angle 4\). Запиши значения всех трёх оставшихся углов.

Вопрос в конце: какие две вещи ты теперь проверяешь до раскрытия скобок?
