# Блок 1. Наблюдение, гипотеза, доказательство

1. Раскрой скобки и приведи подобные:

\[
(t-3)(t+3),\qquad (t-5)(t+5).
\]

2. Сравни результаты. Предположи, чему равно

\[
(u-v)(u+v).
\]

3. Докажи свою гипотезу раскрытием скобок для произвольных \(u\) и \(v\).

4. Объясни одной фразой, почему два средних слагаемых исчезают.

5. Используй доказанную формулу, не возводя большие числа в квадрат:

\[
2026^2-2024^2.
\]

# Блок 2. Телескоп с правильными границами

Первый член суммы можно записать так:

\[
21=11^2-10^2.
\]

1. Запиши аналогично \(23\), \(25\) и \(39\).

2. Составь цепочку для всей суммы

\[
21+23+25+\ldots+39
\]

и явно укажи, какие квадраты сокращаются.

3. Получи ответ без поочерёдного сложения всех чисел.

4. Докажи общую формулу:

\[
(2m+1)+(2m+3)+\ldots+(2n-1)=n^2-m^2,
\]

где \(0\le m<n\).

5. Примени её к новой сумме:

\[
101+103+105+\ldots+199.
\]

# Блок 3. Условие тоже участвует в решении

Лена предложила пару \(a=0\), \(b=1\) как самый маленький положительный контрпример к утверждению

\[
(a+b)^2=a^2+b^2.
\]

1. Назови две разные причины, почему ответ Лены не подходит.
2. Найди самый маленький контрпример с положительными целыми \(a\) и \(b\).
3. Докажи, что меньшего положительного контрпримера нет.

# Блок 4. Средний коэффициент не выбирают

Известно, что \(p\) и \(q\) - положительные целые числа и

\[
(px+q)^2=81x^2+cx+25.
\]

1. Найди \(p\), \(q\) и \(c\).
2. Объясни, почему другого положительного значения \(c\) быть не может.
3. Может ли многочлен

\[
81x^2+88x+25
\]

быть квадратом двучлена с положительными целыми коэффициентами? Ответ обоснуй без перебора.
4. В чужом решении написано:

\[
(7x+4)^2=49x^2+52x+16.
\]

Найди одну ошибочную арифметическую операцию, не раскрывая квадрат заново.

# Блок 5. Необязательный исследовательский перенос

Докажи, что квадрат любого нечётного целого числа, уменьшенный на \(1\), делится на \(8\).

Начни с записи нечётного числа в виде

\[
2k+1
\]

и постарайся использовать разность квадратов.
