> Смотреть нужно максимально прицельно: правило умножения и деления неравенства на отрицательное число. Главная мысль дня: при делении на отрицательное число знак меняется, но строгий или нестрогий тип знака сохраняется.

# Мини-памятка

\[
\le \Rightarrow \ge,\qquad
\ge \Rightarrow \le,\qquad
< \Rightarrow >,\qquad
> \Rightarrow <
\]

Пример: \(-2x \le 8 \Rightarrow x \ge -4\).  
Не надо превращать неравенство в равенство.

# Блок 1. Исправляем вчерашние места

1. \(-2x \le 8\)
2. \(-5x > 15\)
3. \(-0{,}5x \ge 3\)
4. \(-4(x - 1) < 12\)

# Блок 2. Знак меняется, тип знака сохраняется

1. \(-3x \le 12\)
2. \(-4x < 20\)
3. \(-0{,}25x \ge 1\)
4. \(-1{,}5x > 6\)
5. \(-6x \le -18\)
6. \(-0{,}2x < -1\)

# Блок 3. Скобка плюс неравенство

1. \(-2(x + 3) \le 10\)
2. \(-3(x - 4) > 6\)
3. \(-0{,}5(x + 2) \ge 3\)
4. \(-4(2 - x) < 12\)

# Блок 5. Геометрия на поддержание

1. Один из смежных углов равен \(64^\circ\). Найди второй.
2. При пересечении двух прямых один угол равен \(110^\circ\). Найди остальные три угла.
3. Вертикальные углы равны \(3x + 10^\circ\) и \(70^\circ\). Найди \(x\).
