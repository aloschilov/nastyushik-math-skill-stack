> Главный акцент: при делении на отрицательное число знак меняется, но строгий или нестрогий тип сохраняется. \(\le\) становится \(\ge\), а не просто \(>\).

# Блок 1. Вчерашние места

1. \(-2x \le 8 \Rightarrow x \ge -4\).
2. \(-5x > 15 \Rightarrow x < -3\).
3. \(-0{,}5x \ge 3 \Rightarrow x \le -6\).
4. \(-4(x - 1) < 12 \Rightarrow -4x + 4 < 12 \Rightarrow -4x < 8 \Rightarrow x > -2\).

# Блок 2. Знак и тип знака

1. \(-3x \le 12 \Rightarrow x \ge -4\).
2. \(-4x < 20 \Rightarrow x > -5\).
3. \(-0{,}25x \ge 1 \Rightarrow x \le -4\).
4. \(-1{,}5x > 6 \Rightarrow x < -4\).
5. \(-6x \le -18 \Rightarrow x \ge 3\).
6. \(-0{,}2x < -1 \Rightarrow x > 5\).

# Блок 3. Скобка плюс неравенство

1. \(-2x - 6 \le 10 \Rightarrow -2x \le 16 \Rightarrow x \ge -8\).
2. \(-3x + 12 > 6 \Rightarrow -3x > -6 \Rightarrow x < 2\).
3. \(-0{,}5x - 1 \ge 3 \Rightarrow -0{,}5x \ge 4 \Rightarrow x \le -8\).
4. \(-8 + 4x < 12 \Rightarrow 4x < 20 \Rightarrow x < 5\). Здесь деления на отрицательное число в последнем шаге нет, знак не меняется.

# Блок 4. Многочлены

1. \(3a + 3b\).
2. \(3x^2 - 3x\).
3. \(10m - 2n\).
4. \(5p - 3q\).

# Блок 5. Геометрия

1. \(180^\circ - 64^\circ = 116^\circ\).
2. Остальные углы: \(70^\circ\), \(110^\circ\), \(70^\circ\).
3. \(3x + 10^\circ = 70^\circ \Rightarrow 3x = 60 \Rightarrow x = 20\).

# Что считать успехом

- В блоках 1-3 нет ответов через знак равенства там, где было неравенство.
- В ответах с \(\le\) и \(\ge\) не потеряна черта под знаком.
- В многочленах нет смешивания \(x^2\) с \(x\), \(m\) с \(n\).
- Геометрия проверена через \(180^\circ\) или равенство вертикальных углов.
