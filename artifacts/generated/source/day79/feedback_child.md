# Что ещё нужно доказать

Фраза «для каждого \(\alpha\) существуют ровно два луча» относится не только к \(\alpha=90^\circ\). Нужно отдельно показать:

1. луч существует в каждой из двух полуплоскостей, значит, решений не меньше двух;
2. в каждой полуплоскости луч единственный, значит, решений не больше двух.

В блоке 4 гипотеза названа, но два направления не записаны. Для полного доказательства нужны две разные цепочки:

\[
OR,\ OS\text{ противоположные}
\Rightarrow
\angle ROS=180^\circ
\Rightarrow
\beta+\gamma=180^\circ;
\]

\[
\beta+\gamma=180^\circ
\Rightarrow
\angle ROS=180^\circ
\Rightarrow
OR,\ OS\text{ противоположные}.
\]

На первом рисунке подписано \(\angle POS=180^\circ\), хотя развёрнутым является \(\angle ROS\). Это важно: три буквы должны называть именно тот угол, о котором сделан вывод.
