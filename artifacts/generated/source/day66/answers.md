> Главный акцент: не требовать длинных формулировок. Достаточно коротко назвать логическую причину, но нельзя заменять общее доказательство одной удачной подстановкой.

# Блок 1. Найди разрыв в доказательстве

1. Миша доказал равенство только для пары \(a=7\), \(b=4\). Для всех целых чисел оно ещё не доказано.

2.

\[
\begin{aligned}
(a+b)^2-(a^2+b^2)
&=a^2+2ab+b^2-a^2-b^2\\
&=2ab.
\end{aligned}
\]

3. Исходное равенство выполняется тогда и только тогда, когда

\[
2ab=0.
\]

Произведение целых чисел равно нулю, если хотя бы один множитель равен нулю. Поэтому

\[
a=0\quad\text{или}\quad b=0.
\]

4. Самый маленький положительный контрпример: \(a=1\), \(b=1\):

\[
(1+1)^2=4,\qquad 1^2+1^2=2.
\]

Меньшего положительного целого числа, чем \(1\), нет.

# Блок 2. Почини телескоп

1. Правильная цепочка:

\[
1^2-0^2=1,
\]

\[
2^2-1^2=3,
\]

\[
3^2-2^2=5,
\]

\[
4^2-3^2=7.
\]

2. При сложении получаем

\[
(1^2-0^2)+(2^2-1^2)+(3^2-2^2)+(4^2-3^2)=4^2-0^2=16.
\]

Промежуточные \(1^2\), \(2^2\), \(3^2\) входят по одному разу со знаком плюс и по одному разу со знаком минус.

3. Складываем равенства

\[
(k+1)^2-k^2=2k+1
\]

для \(k=m,m+1,\ldots,n-1\). Все промежуточные квадраты сокращаются:

\[
(2m+1)+(2m+3)+\ldots+(2n-1)=n^2-m^2.
\]

4. Здесь \(2m+1=21\), поэтому \(m=10\); и \(2n-1=39\), поэтому \(n=20\). Следовательно,

\[
21+23+\ldots+39=20^2-10^2=400-100=300.
\]

# Блок 3. Коэффициент под следствием

Из крайних членов:

\[
r^2=49,\qquad s^2=16.
\]

Поскольку \(r\) и \(s\) положительны,

\[
r=7,\qquad s=4.
\]

Поэтому средний коэффициент вынужден:

\[
c=2rs=2\cdot7\cdot4=56.
\]

Другого значения быть не может, потому что положительные квадратные корни из \(49\) и \(16\) единственны.

Многочлен \(49x^2+54x+16\) не может иметь требуемый вид: крайние члены снова вынуждают \(u=7\), \(v=4\), а тогда средний член равен \(56x\), а не \(54x\).

# Блок 4. Почему хватает одного уравнения

Пусть меньший угол равен \(x\), тогда второй равен \(3x-36^\circ\). Смежные углы в сумме дают \(180^\circ\):

\[
x+(3x-36^\circ)=180^\circ.
\]

\[
4x=216^\circ,\qquad x=54^\circ.
\]

Смежный угол:

\[
3\cdot54^\circ-36^\circ=126^\circ.
\]

Вертикальные углы равны, поэтому все четыре угла:

\[
54^\circ,\quad126^\circ,\quad54^\circ,\quad126^\circ.
\]

Ожидаемое объяснение: уравнение определило два смежных угла, потому что их сумма равна \(180^\circ\). Два остальных определились без новых уравнений, потому что вертикальные углы равны.

Если один угол равен \(\alpha\), то вертикальный ему тоже равен \(\alpha\), а два смежных равны

\[
180^\circ-\alpha.
\]

# Блок 5. Проверка математической силы

1. Один неверный случай опровергает утверждение «для всех».
2. Один верный случай подтверждает только этот случай и не доказывает утверждение «для всех».
3. Буквенная цепочка для произвольных допустимых значений может доказать утверждение «для всех».

# Что считать успехом

- Числовой пример явно отделён от общего доказательства.
- Из \(2ab=0\) получены оба семейства решений.
- В телескопической цепочке каждый раз вычитается предыдущий квадрат.
- Сумма от \(21\) до \(39\) найдена как разность квадратов, а не прямым сложением.
- Обязательный коэффициент \(56\) доказан через крайние члены.
- Причина достаточности одного уравнения названа двумя свойствами углов.
