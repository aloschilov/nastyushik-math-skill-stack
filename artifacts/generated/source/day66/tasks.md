Смотри с начала до момента, когда сформулированы и объяснены свойства смежных и вертикальных углов. Затем остановись, закрой источник и запиши оба свойства своими словами. Максимум \(7\) минут.

> Разрешённый инструмент:
\[
(a+b)^2=a^2+2ab+b^2.
\]

# Блок 1. Найди разрыв в доказательстве

Миша написал:

> При \(a=7\), \(b=4\) разность \((a+b)^2-(a^2+b^2)\) равна \(56\), и \(2ab=56\). Значит, для всех целых \(a\) и \(b\)
> \[
> (a+b)^2-(a^2+b^2)=2ab.
> \]

1. Что именно доказал Миша, а что осталось недоказанным?
2. Докажи равенство для всех целых \(a\) и \(b\), не подставляя числа.
3. Используя полученную разность, найди все целые пары \(a,b\), для которых

\[
(a+b)^2=a^2+b^2.
\]

4. Найди самый маленький контрпример с положительными \(a\) и \(b\). Объясни, почему меньшего положительного контрпримера быть не может.

# Блок 2. Почини телескоп

В цепочке допущены ошибки:

\[
1^2-0^2=1,
\]

\[
2^2-0^2=3,
\]

\[
3^2-0^2=5,
\]

\[
4^2-0^2=7.
\]

1. Измени только неверные вычитаемые так, чтобы каждое равенство стало верным.
2. Сложи исправленные равенства. Явно зачеркни или выпиши слагаемые, которые сокращаются.
3. Докажи общую формулу

\[
(2m+1)+(2m+3)+\ldots+(2n-1)=n^2-m^2,
\]

где \(0\le m<n\).
4. Не складывая по одному, вычисли

\[
21+23+25+\ldots+39.
\]

# Блок 3. Коэффициент под следствием

Известно, что \(r\) и \(s\) - положительные целые числа, а

\[
(rx+s)^2=49x^2+cx+16.
\]

1. Найди \(r\), \(s\) и \(c\).
2. Докажи, что другого значения \(c\) при этих условиях быть не может.
3. Можно ли подобрать положительные целые \(u\) и \(v\), чтобы

\[
(ux+v)^2=49x^2+54x+16?
\]

Не перебирай пары: используй крайние члены.

# Блок 4. Почему хватает одного уравнения

Две прямые пересекаются. Один угол на \(36^\circ\) меньше утроенного смежного с ним угла.

1. Нарисуй две пересекающиеся прямые и обозначь меньший из этих смежных углов через \(x\).
2. Составь одно уравнение и найди все четыре угла.
3. Закончи объяснение:

> Уравнение определило два смежных угла, потому что ...

> Два остальных угла определились без новых уравнений, потому что ...

4. Запиши без чисел: если один угол при пересечении двух прямых равен \(\alpha\), чему равны остальные три?

# Блок 5. Проверка математической силы
