> Главный акцент: в вычитании многочленов меняются все знаки второй скобки; в неравенствах нужен один финальный ответ.

# Блок 1. Ловушка со знаком

1. \(6m - 4n - 2m + 7n = 4m + 3n\).
2. \(5a - 3b - 2a + 6b = 3a + 3b\).
3. \(8x - 2y - 3x + 5y = 5x + 3y\).
4. \(4p + q - p + 2q = 3p + 3q\).

# Блок 2. Многочлены

1. \(5x - 4\).
2. \(5a - 10\).
3. \(2x^2 + 8x\).
4. \(11m - 3n\).
5. \(4a^2 + 4a\).
6. \(6p - 5q\).

# Блок 3. Неравенства

1. \(-2x \le 8 \Rightarrow x \ge -4\).
2. \(-5x > 15 \Rightarrow x < -3\).
3. \(-0{,}5x \ge 3 \Rightarrow x \le -6\).
4. \(-4(x - 1) < 12 \Rightarrow -4x + 4 < 12 \Rightarrow -4x < 8 \Rightarrow x > -2\).

# Блок 4. Уравнения и тождества

1. \(2{,}5x = 15 \Rightarrow x = 15 : 2{,}5 = 6\).
2. \(3(x - 2) = 12 \Rightarrow x - 2 = 4 \Rightarrow x = 6\).
3. \(-3(a - 4) = -3a + 12\).
4. При \(x = 2\): \(5 \cdot 1 = 5\), а \(10 - 5 = 5\). Равны.

# Блок 5. Геометрия

1. \(180^\circ - 48^\circ = 132^\circ\).
2. Вертикальный угол тоже \(82^\circ\).
3. Остальные углы: \(60^\circ\), \(120^\circ\), \(60^\circ\).

# Что считать успехом

- В блоке 1 после раскрытия второй скобки знак перед вторым слагаемым стал плюсом.
- В каждом неравенстве есть один ответ вида \(x \ge \ldots\), \(x < \ldots\), \(x \le \ldots\), \(x > \ldots\).
- В уравнениях есть строка деления или аккуратный переход после скобок.
- Геометрия проверена правилом \(180^\circ\) или равенством вертикальных углов.
