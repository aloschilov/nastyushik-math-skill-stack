> Главный акцент: правильное раскрытие скобок ещё не завершает решение. Итоговая строка должна содержать приведённый многочлен.

# Блок 1. Вчерашние примеры

1. \(a^2+5a+a+5=a^2+6a+5\).
2. \(c^2-2c-3c+6=c^2-5c+6\).

# Блок 2. Три полных решения

Первый пример:

\[
(m+2)(m+6)=m^2+6m+2m+12\Rightarrow\text{Ответ: }m^2+8m+12.
\]

Второй пример:

\[
(n+5)(n-3)=n^2-3n+5n-15\Rightarrow\text{Ответ: }n^2+2n-15.
\]

Третий пример:

\[
(k-4)(k-1)=k^2-k-4k+4\Rightarrow\text{Ответ: }k^2-5k+4.
\]

# Блок 3. Недостающая строка

\[
\text{Ответ: }p^2+p-6.
\]

# Блок 4. Проверка

При \(k=0\):

\[
(0-4)(0-1)=4,\qquad 0^2-5\cdot0+4=4.
\]

Значения совпали.

# Блок 5. Поддержание

1.
\[
5-7x\ge19\Rightarrow-7x\ge14\Rightarrow x\le-2.
\]

2. Вертикальный угол равен \(128^\circ\). Два смежных угла равны \(180^\circ-128^\circ=52^\circ\). Ответ: \(128^\circ\), \(52^\circ\), \(52^\circ\).

# Что считать успехом

- Во всех трёх новых примерах есть отдельная итоговая строка.
- Исходные числа и буква сохранены.
- В геометрии перечислены все три оставшихся угла.
