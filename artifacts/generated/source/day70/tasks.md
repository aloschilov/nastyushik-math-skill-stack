> Сначала прочитай новое пособие. Затем закрой его: сегодня оценивается не память на формулу, а способность самой восстановить сокращение.

# Блок 1. Восстановить исчезнувшие части

Дана сумма

\[
33+35+37+39.
\]

1. Представь каждый член как разность соседних квадратов.
2. Запиши сумму всех четырёх разностей в одной длинной строке.
3. Перепиши строку так, чтобы одинаковые квадраты с противоположными знаками стояли рядом.
4. Обведи пары, равные нулю. Какие два квадрата остались?
5. Вычисли сумму через оставшуюся разность квадратов и проверь обычным сложением.

# Блок 2. Восстановить сумму по двум краям

Известно, что телескопическая сумма нечётных чисел свернулась в

\[
18^2-11^2.
\]

Не вычисляй квадраты сразу.

1. Восстанови первый и последний члены исходной суммы.
2. Запиши всю сумму с многоточием.
3. Найди число её членов двумя способами.
4. Только после этого вычисли сумму.

# Блок 3. Найти ошибку в общей записи

Ученик написал:

\[
(2m+1)+(2m+3)+\ldots+(2n+1)=n^2-m^2.
\]

1. Покажи на последних двух разностях квадратов, где нарушилась цепочка.
2. Исправь либо последний член слева, либо правую часть так, чтобы получилось верное равенство.
3. Объясни исправление словами, не ссылаясь только на готовую формулу.

# Блок 4. Построить собственный телескоп

Составь сумму из **девяти последовательных нечётных чисел**, последний член которой равен \(71\).

1. Найди первый член.
2. Запиши сумму.
3. Вычисли её телескопически.
4. Проверь через число членов и среднее первого и последнего.

# Короткий перенос: насколько сильна делимость

Верно ли утверждение:

> Произведение любых двух последовательных чётных чисел делится на \(16\)?

Если верно - докажи для произвольных чисел. Если неверно - найди контрпример, а затем сформулируй и докажи самое сильное утверждение о делимости, которое гарантировано для каждой такой пары.

# Необязательный олимпиадный перенос

Сколько первых нечётных положительных чисел нужно сложить, чтобы получить \(2025\)? Докажи, что найденное число членов единственно.

# Вопрос о методе

Не используя слова «так написано в формуле», объясни:

1. почему исчезают внутренние квадраты;
2. почему по краям остаются квадраты с разными знаками.
