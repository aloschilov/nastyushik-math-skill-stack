# Skill Gates

## Предметная принадлежность

Gate относится только к своей предметной матрице. Успешное алгебраическое доказательство не считается автоматическим evidence для геометрического или вероятностного рассуждения.

Статус **NEW/0** означает, что gate ещё не проверялся. Первое задание по такому навыку должно быть диагностическим: без предварительного обучения, но с достаточным контекстом для понимания условия.

Порядок curriculum gates задаётся в `data/curriculum/advanced_grade7.csv`. Успешная базовая контрольная подтверждает нижний порог, но не закрывает углублённый gate без задачи на объяснение, доказательство или перенос.

## Gate A: знаки

Навык считается закреплённым, если ребёнок решает 10 коротких примеров подряд без ошибки:

```text
7 - 12 + 5
-9 + 4 - 7
6 - 14 + 5
-10 + 7 - 6
```

## Gate B: десятичные коэффициенты

Закреплено, если 8 примеров подряд решаются без потери коэффициента и знака:

```text
12,5x - 1,2x - 0,8x
3,4x - 1,7x - 0,5x
-2,4b + 0,9b - 1,6b
```

## Gate C: уравнения

Закреплено, если в каждом решении явно есть последний шаг:

```text
2x = 8
x = 8 : 2
x = 4
```

## Gate D: особые уравнения

Нужно различать:

```text
0x = 0      -> любое число
0x = 5      -> нет решений
5x = 0      -> x = 0
```

## Gate E: неравенства

Закреплено, если ответ всегда записывается как условие:

```text
x > 7
x <= -5
```

При делении или умножении на отрицательное число знак меняется:

```text
-2x >= 10
x <= -5
```

## Gate F: текстовые задачи

Минимальный шаблон:

```text
Пусть x — это ...
Таблица: было / стало
Уравнение
Решение
Проверка по смыслу
Ответ словами
```

## Gate G: геометрическое доказательство

Успех требует трёх частей:

1. корректного рисунка и обозначений;
2. явного названия используемого свойства;
3. цепочки от свойства к требуемому выводу.

Верный числовой ответ без причинной цепочки оставляет навык под наблюдением.

## Gate H: вероятность и статистика

Первую диагностику проводить поэтапно:

1. чтение таблиц и диаграмм;
2. среднее, медиана, размах, затем квартили и среднее гармоническое;
3. случайная изменчивость, группировка данных и статистическая устойчивость;
4. графы, пути, циклы и эйлеров обход;
5. условные и обратные утверждения, необходимые и достаточные условия;
6. случайный эксперимент, событие, вероятность и частота.

Не объединять все линии в одну первую работу. Статус повышается только после задания на перенос, а не после воспроизведения определения.

## Gate I: углублённое алгебраическое рассуждение

Вычислительно верная подстановка не считается доказательством тождества. Для прохождения gate ребёнок должен:

1. назвать допустимые преобразования;
2. получить одну и ту же форму из обеих частей или преобразовать одну часть в другую;
3. объяснить, почему рассуждение работает для всех допустимых значений;
4. применить доказанное тождество в новой задаче.

Для делимости и остатков требуется не только ответ, но и обоснование через представление числа, алгоритм Евклида или свойства остатков.

## Gate J: углублённое геометрическое рассуждение

Помимо рисунка и вычисления проверять язык доказательства: условие и заключение, свойство и признак, прямое и обратное утверждения. Задача на построение считается завершённой только при наличии построения, доказательства и исследования числа решений.

## Gate K: функции и модели

Навык не закрывается построением таблицы значений. Требуется переход между формулой, графиком и словесной ситуацией, а также чтение области определения, области значений, нулей, промежутков изменения и особых точек графика.
